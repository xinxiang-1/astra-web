# DM Sans web fonts

These unchanged DM Sans v17 WOFF2 assets are the exact four files returned by the site's existing Google Fonts CSS request for Chrome 154 on Windows. Font metadata identifies version 4.004 and Copyright 2014 The DM Sans Project Authors. They remain UI typography; they are independent of the signature portrait font bank.
