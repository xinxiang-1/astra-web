| --- | --- | --- |

共同生成要求为4:5竖幅、强主体、连续中间调、无字、无水印、无UI。上表是场景摘要；本次接续记录无法取得此前工具调用的完整逐字提示词，不能冒充完整提示词存档。没有使用私人上传照片。生成来源不等于独占版权或第三方权利认证，1122×1402也不标为原生4K。

复现字符预览：`npm run assets:gallery`。编码脚本只做无损格式转换，未缩放或调色原件。
