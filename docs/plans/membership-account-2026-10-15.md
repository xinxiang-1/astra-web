# 会员账户记录与失效会话恢复

接续[会员后端基础](./membership-backend-2026-10-10.md)。本阶段完成账户中的只读会员记录，保持既有本地创作与导出免费；会员销售、真实付款授予及实际云服务仍须后续实施。

## 实现

`/account/membership` 接本人 `GET /api/system/membership`，订单与已购内容提供入口。页面展示后端给出的有效、冻结、撤销、未生效和到期状态，分别说明使用边界；总额度、已用、预占与账面剩余分别列出。时间以北京时间呈现，状态采用后端判定，不用浏览器日期推断权益。

ID 与数量保持十进制字符串；大数使用 BigInt 格式化，不经浮点数丢失精度。响应必须满足结构、日期、方案额度与桶计数守恒，损坏数据进入可重试错误状态。会员关闭与已开放但无权益分别呈现，云备份和云端渲染标明尚未开放。页面只发读取请求，不创建或消费权益。

每次读取取消前次请求，并核对当前 token 与请求归属。换账户、同用户换 JWT、退出和离页使旧响应失效。刷新按钮始终保留，使用 aria-disabled 与点击门禁避免重复提交和加载时丢失焦点；成功更新与加载通过状态区域播报，故障可原地重试。

审核发现冷启动时 `auth.user` 本来就是 null，`auth/me` 的权威 401 清 token 后没有通知账户观察者，可能留下空白状态或旧权益。本次复用会话失效机制更新 revision；保留原请求代次检查，迟到的旧 401 仍不能清除新账户。HTTP 503（即使业务 code 是 401）继续保留凭据，不误判为退出。

## 验证与证据

本阶段使用 astra-web-validation、astra-cloud-validation、Impeccable 与 Playwright。API 合同覆盖合法状态、大数、日期及损坏余额/能力、取消和 HTTP 401/503；Store 合同增加冷启动身份观察回归。上轮已证明原实现失败，本轮以当前源码重跑：会员 API 27 项、HTTP 8 项、会话 7 项，以及 Edge/Chrome 身份合同各27项通过。

真实后端页面验收由后端拥有的随机 MySQL schema、独占 Redis/system/gateway 驱动，读取五状态及通过内部 reserve/commit 构造的非零用量。浏览器仅接受 loopback 控制端口与父进程随机密钥，不允许单独对共享服务执行。关闭、空记录、重试、换账户、同用户换 token、长名字、双主题和窄屏均有行为检查。另以受控 auth/me401 和真实会员响应的两种顺序，验证冷启动失效会话；常规 auth/me 使用明确的503替身。

2026-10-15 当前生产构建验收通过：会员19项（含浏览器父夹具）、网关20项JUnit，Edge/Chrome各13条页面检查；OpenAPI验证21条后端HTTP、56条浏览器真实HTTP。`--require-browser` 校验证据及清理通过。源代码类型检查、定向ESLint、生产构建、Impeccable机械检测与文档链接通过。构建仍提示既有大chunk、签名布局混用静态/动态import和Office流模块兼容警告，这些不是本阶段修复范围。主库未迁移、会员未启用，共享MySQL/Redis保持运行。

已目视审查桌面/390px两主题、非零额度及112字长名字截图；未以模拟窄屏代替实体触控设备验收。源码哈希、当前身份合同与命令结果见[证据清单](../validation/2026-10-15/membership-account/manifest.json)，真实HTTP、14幅截图及资源清理在[后端证据](../../../astra-cloud/docs/validation/2026-10-15/membership-account/)中保留，可重放验证。

后端运行方式及权限边界见[会员运行合同](../../../astra-cloud/docs/commerce/membership-runtime.md)和[后端阶段记录](../../../astra-cloud/docs/plans/membership-account-2026-10-13.md)。夹具 JWT、测试订单及权益不证明真实会员购买、商户资金、云任务或真机体验。

## 接续

下一性能阶段处理编辑器全屏时普通/全屏两画布分别维护 Worker 和场造成的重复绘制；应迁移同一渲染会话的呈现目标，保留交互连续性、真实时钟与画质，不能以关闭效果或降低品质代替。之后继续逐字 GPU 几何与长媒体分页缓存，目标仍是等待解析后高画质、高帧率和交互共同流畅。

完整会员销售需冻结不可变 offer/条款，连接可信付款与退款来源，再接真实服务消费者。人工注册、前后端与 Nacos/Redis/MySQL 部署继续以[用户准备与部署手册](../../../astra-cloud/docs/deployment/user-setup-guide.md)为入口。
