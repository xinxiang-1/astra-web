# Studio 交互底座与后续特效标准

2026-10-03用户要求暂停；2026-10-04用户已明确恢复并增加全站一致性及商业品质目标。[暂停交接](./project-pause-handoff-2026-10-03.md)保留既有成果，当前工作与门槛见[六方向接续计划](./commercial-quality-execution-2026-10-04.md)。

用户于2026-10-02确认：后续开发特效统一对标原生Studio，可以在原生引擎基础上接入Astra引擎并创新，追求强烈、有层次的视觉效果。本标准适用于后续创作特效开发；首页主图保持既有Studio表现。

## 已采用的路线

Astra继续负责六模式采样、原生字体、画质、中文铺字、本地项目及免费导出。交互层移植asciify-engine 4.1原生MIT字段算法：流体拖尾、波动水面、丝绸/漩涡残像、扩散等高圈及溶解。交互输出为位移与密度信号，由统一Canvas及软件面积栅格消费，离线HTML内嵌相同工厂。光晕在原生渐入/渐出基础上由实际字符遮罩产生，涟漪/轻推使用水面/丝绸场的独立映射。

不为悬停切换整套采样引擎，避免静态与动态画质、字体、文案和导出不一致。原生底座保留固定步进、有限网格和强度/范围；未来可用renderer.sampleInteraction读取同一场，供粒子、边缘或光场层消费。此接口只读场数据，不改变原图或字形。

## 推荐的引擎结构

采用“原生 Studio 交互场 + Astra 字符绘制 + 创新表现层”。输入和场模拟只维护一份状态；画质、中文句序和字形继续由 Astra 处理；新的撕裂、聚散、反光由同一场驱动。普通 Canvas、软件面积栅格和离线 HTML 共用工厂，未来 GPU 加速也须先证明与该合同一致。

现有只读入口属于 `createCanvasArtRenderer`，并非 `createArtRenderer` 包装器的公开方法。`sampleInteraction(x, y)` 的 x/y、density、trailX/trailY 分别是场位移、密度和拖尾位移；它没有公开原始速度。需要速度、梯度或涡量时，应明确扩展共享场接口、坐标单位和版本，并让离线输出共同支持，不能把当前位移直接当成速度。

2026-10-03新增只读 `sampleFluidField(x,y)`：velocityX/Y为原生拖尾u/v除以对应网格跨度的UV/秒，offsetX/Y为同样换算的UV位移，density为原生信号；未应用用户强度、不推进场或暴露可写数组，非拖尾/无活动场返回零。旧sampleInteraction字段保持原意义。当前只供[撕裂原型](./studio-rift-prototype-2026-10-03.md)使用，尚未将新交互参数接入正式编辑器/项目/输出。

“炸裂”的设计目标是一次交互就能看清主形变，快速划动留下有层次的余波，松手后作品自然重组。每个效果安排一个主要形变、一种局部细节和一种恢复方式，反光/粒子从原作字形及颜色产生。首页原作仍是基础手感的对照；网页按钮与滚动动效沿用作品的色彩和节奏，按各自载体实现。

先提供打磨好的预设及已有强度/范围控制。底层可组合不等于同时启用全部效果；先验证各效果自身，再证明组合后的主体、方向和性能可靠。新增参数需进入本地项目、`.astra`、脏状态、HTML及视频快照；旧项目继续按既有 profile 恢复。

## 每种新特效必须达到的标准

- 连续指针路径有连续反馈，快速划动与缓慢移动能产生合理区别；无断裂圆点、瞬间跳变或无效hover。
- 停止输入后有自然余波、回弹或重组，离开后最终恢复原作；鼠标静止不能依靠时间噪声不停破坏画面。
- 视觉至少有主形变、局部细节和清晰轮廓；强烈效果仍保持作品可辨识，文字不镜像或倒置。
- 所有六模式、适用品质档及透明/PNG/视频/HTML均使用同一静态画质和参数合同。暂停环境动画仍可交互，零强度逐像素恢复静态。
- 实际画布坐标适配缩放与全屏；支持触控释放、减少动效、标签页隐藏和离屏停止。说明真实性能范围，不凭截图承诺手机或4K的60fps。
- 用独立原生Studio参考和真实页面的相同素材/轨迹验收，保留前后截图、动态演示、失败及源码hash；每个可验收小阶段提交立即推送。

## 创新顺序

1. 流体撕裂与回弹：由当前速度场驱动连续位移、边缘反光和字密度，减少无关装饰。
2. 粒子聚散：同一字形/颜色采样，指针能量驱动散开与重组，回到原图结构。
3. 光场冲击与层叠涟漪：利用真实字符遮罩与有限光源，避免一片泛白。

先各做一个能实际操控、参数可保存和可离线导出的候选，再按用户视觉反馈筛选；不一次添加大量只有名字不同的按钮。原创模板包和定制服务可在实际验收后使用这些效果，免费已有导出保持。

## 下一阶段的交付顺序

1. **流体撕裂原型**：已进入[可操作候选阶段](./studio-rift-prototype-2026-10-03.md)，[原型入口](../prototypes/v7-studio-rift/index.html)。同一原生速度/密度梯度/回弹位移驱动撕开与字形反光；与冻结0ad0a5f拖尾同素材、同强度/范围/事件序列并排。新API单位与独立原生引擎核对，默认旧表现保留；用户审美、性能与正式项目/输出接通仍未完成。
2. **六模式与输出接通**：视觉候选通过后，再冻结效果 API，接入适用品质、预览/全屏、触控、暂停、减少动效、项目/作品包、PNG与离线 HTML；视频明确验证环境动画与参数快照，交互轨迹录制若新增须另立合同。
3. **粒子与光场候选**：逐个复用共享场及真实字形开发，分别验证散开重组、光场冲击与层叠涟漪；每个候选独立验收、记录和提交推送。
4. **商业模板和定制样例**：使用已验收效果制作原创模板、官网案例及宣传片，把模板内容、付费新增创作能力和特效定制服务接进商业交付；已有免费输出继续免费。

每个候选检查慢拖、快速 S 路径、绕圈、停住、离开及重新进入；环境动效暂停后比较最终恢复像素，并查看完整动态片段。分别记录主形变是否清晰、主体是否可辨识、细节是否跟随场、复原是否自然。数值检查与人工视觉结论分别记录，未通过的候选保留在原型，不凭更高亮度或更多选项晋升。

固定画布尺寸、列数、素材、设备和品质报告实际帧耗时、内存及退场时间；发现性能问题时先分析场采样、字形栅格和光层的实际成本，再决定是否需要 GPU，避免提前维护第二套不一致的引擎。
