# Studio 交互底座与后续特效标准

用户于2026-10-02确认：后续开发特效统一对标原生Studio，可以在原生引擎基础上接入Astra引擎并创新，追求强烈、有层次的视觉效果。本标准适用于后续创作特效开发；首页主图保持既有Studio表现。

## 已采用的路线

Astra继续负责六模式采样、原生字体、画质、中文铺字、本地项目及免费导出。交互层移植asciify-engine 4.1原生MIT字段算法：流体拖尾、波动水面、丝绸/漩涡残像、扩散等高圈及溶解。交互输出为位移与密度信号，由统一Canvas及软件面积栅格消费，离线HTML内嵌相同工厂。光晕在原生渐入/渐出基础上由实际字符遮罩产生，涟漪/轻推使用水面/丝绸场的独立映射。

不为悬停切换整套采样引擎，避免静态与动态画质、字体、文案和导出不一致。原生底座保留固定步进、有限网格和强度/范围；未来可用renderer.sampleInteraction读取同一场，供粒子、边缘或光场层消费。此接口只读场数据，不改变原图或字形。

## 每种新特效必须达到的标准

- 连续指针路径有连续反馈，快速划动与缓慢移动能产生合理区别；无断裂圆点、瞬间跳变或无效hover。
- 停止输入后有自然余波、回弹或重组，离开后最终恢复原作；鼠标静止不能依靠时间噪声不停破坏画面。
- 视觉至少有主形变、局部细节和清晰轮廓；强烈效果仍保持作品可辨识，文字不镜像或倒置。
- 所有六模式、适用品质档及透明/PNG/视频/HTML均使用同一静态画质和参数合同。暂停环境动画仍可交互，零强度逐像素恢复静态。
- 实际画布坐标适配缩放与全屏；支持触控释放、减少动效、标签页隐藏和离屏停止。说明真实性能范围，不凭截图承诺手机或4K的60fps。
- 用独立原生Studio参考和真实页面的相同素材/轨迹验收，保留前后截图、动态演示、失败及源码hash；每个可验收小阶段提交立即推送。

## 创新顺序（尚未开发）

1. 流体撕裂与回弹：由当前速度场驱动连续位移、边缘反光和字密度，减少无关装饰。
2. 粒子聚散：同一字形/颜色采样，指针能量驱动散开与重组，回到原图结构。
3. 光场冲击与层叠涟漪：利用真实字符遮罩与有限光源，避免一片泛白。

先各做一个能实际操控、参数可保存和可离线导出的候选，再按用户视觉反馈筛选；不一次添加大量只有名字不同的按钮。原创模板包和定制服务可在实际验收后使用这些效果，免费已有导出保持。
