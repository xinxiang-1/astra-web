# 完整签名沿轮廓排布

用户提出名字方向也可塑造画像，疏密保持接近。保留生产默认“自然织排”，增加可选“沿画像轮廓”和折叠面板中的方向引导强度。方向模式进入计算 Worker、控件快照、PNG / Path SVG / JSON 与 `.astra-signature` 恢复参数；选择方向时使用 woven，旧 stipple 项目不选择新模式时保持原参数。这不是重启已停止的容量 R1 / R2 或旧 ink-pack / native 候选。

画像在最长边 1024 的分析图上计算 Sobel 梯度。平滑局部结构张量的积分图提供主轮廓切线、相干性和梯度能量。低能量 / 多方向区域减弱引导；轴方向映射到最接近写字基线的角度，默认水平或用户主动选择的竖排都不会反向。方向引导上限 25°，仍受用户角度范围限制。

每枚名字保持原落点、模板索引和旋转包围盒所属格子。根据实际模板宽高拟合尺寸；通过二分限制单枚有效墨迹面积损失不超过原版 15%，现有透明度公式补偿墨量。强暗部透明度上限仍会限制补偿，不宣称所有素材完全等密度。长签名因此角度更克制，轮廓方向是附加结构而非夸张随机倾斜。

## 实际失败及修复

- 第一次 UI 合同把生成中暂时不存在的按钮判为就绪，读到空作品。改为确认真实按钮可用及结果存在。
- 真画像导出暴露近平坦区域积分差的浮点舍入：张量迹可微小为负，开方产生 NaN，个别签名几何失效并拖慢导出。对迹下限夹到零，并验证真画像所有落点数字有限。独立 5031 点真实画像对照：旧方向场 2 个非有限置信度，新场 0 个。完整生成 / PNG / 保存 / 重开通过。未将超时简单当作机器慢，也没有改像素一致性门槛。
