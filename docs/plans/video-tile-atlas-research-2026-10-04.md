# 视频彩色图集性能对照

接续[上传视频响应阶段](./video-responsive-playback-2026-10-04.md)，研究逐字 GPU 着色 / 提交成本。生产基线为 `c795d97d7b03aedfef5ae24710c0f0910002e7a4`。本阶段保留三轮独立算法对照，**图集未接入生产**：最后仍有中英铺字交互像素差异，不因更快或平均差小而放宽原画面合同。生产 Worker、六模式、默认颜色、清晰度及免费导出保持基线。

## 方法

将最多 512 个不同的字形 + 完整 RGB 组合批量绘制到一张 GPU Canvas 图集，按原字格顺序、位置、尺寸和透明度绘回目标；重复组合共用槽位，命令和图集均有上限。着色仍用原 `drawImage` + `source-in`，不用 CPU 颜色量化或替换字体。对图集局部裁剪防止 source-in 清除其它槽位，保留源字符及共享流体工厂。

对照为 Edge 154.0.4258.53 的独立 OffscreenCanvas，两个 source（渐变 / 原创瓷像）、六模式、120 列、900px 输出、static / breathe / rift、不透明 / 透明，共 72 组；本轮全部启用 colored，phrase 包含中文、空格及 ASTRA。两侧均使用 GPU 后端、同一采样结果和 64 个普通 tile 缓存，最终逐通道 RGBA 比较。没有在图集研究中换采样算法、修改生产 Canvas 或换用软件滤镜。

## 三轮实际结果

| 轮次 | 修改及假设 | RGBA 完全相同 | 实际失败 |
| --- | --- | --- | --- |
| R1 | 每槽位 1px 透明边界，降低逐字 bitmap 分配与源修改 / 目标读取切换 | 36 / 72 | density / color / phrase / contour 有差异，最多 7051 个通道值、最大差 255；透明 RGB 读回也计入合同 |
| R2 | 先给原 glyph 四边和角落复制边缘像素，模拟独立纹理的边界钳制 | 60 / 72 | 五模式全部零差，phrase 的 12 组仍不同，最多 1111 个通道值、最大差 85 |
| R3 | 图集宽高改为二次幂，使归一化纹理坐标更精确 | 68 / 72 | phrase 静态及 breathe 均零差；两源 rift × 透明 / 不透明四组仍不同，最多 32 个通道值；不透明最大差 1，透明最大差 85 |

R3 图集为 1 / 2 MiB，另有复制边缘的 glyph 缓存；不是总 GPU 内存认证。R2 / R3 没有通过画质，因此按 fail-closed 门槛未继续性能测量。三轮报告 `errors: []` 仅表示没有页面异常，`parityPassed: false` 才是结论；脚本返回 1 是预期的拒绝，不是产品回归通过。

R1 另做真实瓷像、900px 输出的成图成本对照：180 / 360 列 × color / phrase / halftone，每组 2 次预热、10 次测量，轮流交换两侧先后顺序。每帧采用新的 frame 对象，模拟实时转换的缓存重建；读回 1 像素等待 GPU 当前绘制完成。

| 模式 / 列数 | 基线 P50 / P95 ms | R1 图集 P50 / P95 ms |
| --- | --- | --- |
| color / 180 | 470.4 / 531.0 | 229.9 / 253.3 |
| phrase / 180 | 704.8 / 859.4 | 315.9 / 340.2 |
| halftone / 180 | 477.6 / 521.9 | 233.2 / 264.3 |
| color / 360 | 1863.3 / 2013.7 | 804.0 / 1114.2 |
| phrase / 360 | 2961.4 / 3351.4 | 1277.4 / 1893.0 |
| halftone / 360 | 1761.5 / 2023.6 | 746.3 / 894.5 |

该成本包括 renderer 调用与 GPU 排空，是本机竖幅静态源的独立测试；不是 720p 横幅视频实播、Worker 端到端耗时、界面输入延迟或真机帧率。候选相对更快仍远离高列数实时要求，不能拿 R1 的收益宣传 R3 或生产性能。

## 证据、检查与下一步

[精简证据](../validation/2026-10-04/video-tile-atlas/)保存每轮完整报告、可恢复源码 diff 和 hash。原始生成源码保留 `test-results/video-atlas-r{1,2,3}-edge-20261004/`。`research:video-atlas` 当前复现 R3，默认画质失败时不跑性能；可以设置 `ASTRA_ATLAS_PARITY_ONLY=1`。`ASTRA_ATLAS_BUILD_ONLY=1` 只生成对照源，最终格式化后的生成源码与 R3 实测源码 SHA-256 一致。

研究脚本语法及相关 ESLint 通过，文档链接、diff 可恢复性和报告 / 源码 hash 核验通过。没有生产源码变更，不重复宣称 type-check / build / 实播回归。只核验了本机 Edge、当前素材 / 字库 / 尺寸，未覆盖全品质、其它字体、Chrome、所有动效、触控或长片播放。

这条图集路径暂时停止调参。下一阶段推进现有粒子候选的生产合同与原创案例内容；视频沿已上线的响应式采样、有限缓存、Worker 和友好等待继续处理，未来使用实际用户素材与设备区分解码及 GPU 问题。整体商业目标仍在执行，研究收益与工程零差均不能替代完整商业审美验收。
