# 签名照片可取消读取与尺寸预算 · 2026-10-09

接续[中文字体分片](./signature-font-subsets-2026-10-09.md)。本阶段解决照片读取等待无法及时取消、过大图片先解码后才拒绝，以及连续换图和离页时的候选资源清理。保持浏览器原生解码、EXIF方向、透明度和实际像素；不调整作品布局、笔迹、字体或免费导出。

## 实施

- 新增公共`image-element.ts`，从原`extract.ts`兼容导出。可选AbortSignal、文件字节/像素/长边预算及超时；预取消、空文件和字节超限先拒绝。默认30秒覆盖文件头读取和原生加载，取消不等候尚未完成的文件头Promise或原生load事件。
- 只读取前256KiB，识别PNG IHDR、JPEG SOF和WebP VP8X/VP8/VP8L尺寸；WebP不要求整个大块位于前缀内。可读尺寸先检查，再检查原生解码后的尺寸。文件头是提示，不替代原生解码；SVG/GIF/BMP、超出前缀的JPEG元数据及未知头仍会先解码后检查，不能保证所有文件在分配解码内存前拒绝。
- 原签名照片入口继续32MiB、48MP、12000像素长边；画像入口64MiB、32MP、32768像素长边；作品包画像、名字库图像和示例读取接32MP/32768与调用者取消。作品包仍保留原有包体/序列化检查和实际RGBA身份。
- 生产画像入口显示“正在读取画像照片”和“取消读取照片”，读取中可重新选择。取消、损坏或超限保留上幅完整预览和原画像名字；每次操作只拥有自己的状态，旧回调不能提交、清除新忙态或重置新文件输入。离页取消候选读取。
- 失败/取消/超时移除候选image src、撤销候选URL，失败的名字库部分读取清理临时Canvas及预览URL。成功URL由调用者持有；取消只停止等待，不修改IndexedDB已存名字库。原只读事务仍自行完成并关闭连接。

## 基线与验证

旧版本在原生load回调人为延迟450ms、20ms取消的控制实验中：`loadImageElement`在466ms仍成功返回，`openSignaturePhoto`到464.3ms才AbortError。新最终Edge分别21.6/20.5ms、Chrome20.8/30.8ms即AbortError，候选URL归零。这是事件延迟实验，不是真实慢手机解码速度或线程性能结论。

Edge154.0.4258.62与Chrome157.0.8081.0各一份最终完整合同通过：

- 12个读取输入逐个完整RGBA与浏览器直接解码零差：既有画像/风景/宠物JPEG、原生编码PNG、三张既有WebP、历史公共签名SVG、控制BMP/透明GIF及EXIF6/8 JPEG。未重编码用户输入，不覆盖所有格式、动画帧、色彩配置或设备。
- 10类拒绝/清理：PNG/JPEG/三类WebP超像素在创建原生Image前拒绝；字节超限、空文件、损坏图、未识别头的原生尺寸超限和短超时。保留原生解码失败报错。
- 5类取消：公共读取、签名照片、悬挂文件头、已部分读取的名字库和作品包内嵌画像；部分名字库取消后原库不变，可重试，候选URL全部释放。
- 独立生产build页面恢复真实作品包，双主题1440/390px取消后全预览RGBA与名字保留；连续换图只采用最新输入，坏图保留最新作品，SPA离页释放候选。8张读取状态截图均人工审查，按钮/反馈清晰，没有390px横向溢出；这不是作品审美或真机验收。

两浏览器既有名字库合同各6组加载/输入/取消、12组几何和4个原生参考，事务失败/冲突保留旧库、并发追加、刷新/390px通过；框选合同各4组通过，仍先按源图框选再提取；作品资产合同各5组通过，源文件字节、向量、完整栅格和模板RGBA保持。类型检查、相关ESLint、最终生产build通过，保留既有大chunk、动态/静态导入和stream浏览器兼容警告。

## 失败及修复

1. build R1被Windows npm PowerShell包装器“Could not determine Node.js install directory”阻止，尚未进入Vite；核实Node v24.12.0与包装器后改用`npm.cmd`，未改系统配置。R2成功，补候选image src清理后R3再次成功，最终UI使用R3。
2. Edge core R1误写`mountain-source.webp`等测试素材名，EncodingError且零输入完成；修正为仓库实际三个WebP路径。
3. Edge core R2在12像素输入后出现Bank retry failed：生成器最少8写法，测试却预期2。修正请求8再取前2，重试正确使用库label/版本。core R3通过，仅预检，不累计最终样本。
4. Edge完整R1的库级12/10/5通过，离页用例因主导航与页脚同名“创作工具”链接触发严格选择器失败；限定“主导航”后Edge R2及Chrome R1完整通过。失败报告保留，不改写或算作最终通过。

原报告/日志、基线脚本、8截图、工程作品包、源码/构建hash及链接检查见[阶段证据](../validation/2026-10-09/signature-image-read/README.md)。共享工作区保留既有特效/研究改动，build不是从干净提交隔离生成的发布包；本阶段未提交这些无关改动，正式部署仍须绑定SHA独立构建。后台仅同步两份文档，未重跑无关后台测试、迁移主库或启用真实收款。
