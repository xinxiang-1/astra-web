# Astra 产品达标后的90天引流与平台推广方案

更新2026-10-08。默认中文创作者、纪念人像用户和设计/品牌客户；预算与转化目标都是验证假设。本轮“推流”先按内容引流和付费分发理解，直播推流另列条件。产品打磨与前后端联调优先，[研发/商户/部署门槛](../../../astra-cloud/docs/plans/launch-readiness-2026-10-08.md)未通过不得用收费广告掩盖产品问题。

## 产品叙事与转化路径

主张“把照片变成由文字组成的作品”。三条内容线：普通照片到中文字符画；名字/纪念日到签名画像；实时视觉到网站/活动特效。视频展示真实结果、实际操作与导出，避免只展示难以复现的沙箱画质。广告不能承诺所有手机实时4K、永久云保存或已上线会员。

普通用户路径：平台真实成品 → 对应授权案例/模板页面 → 无登录免费创作 → 成功导出 → 按需求看新增付费内容 → 登录/条款 → 后端确认支付/权益 → 领取 → 售后。定制路径：案例 → 范围/设备/交付说明 → 咨询 → 人工需求确认/报价 → 合同/里程碑 → 验收；不把咨询点击当成交。

已有免费功能继续免费；会员未实现时不营销“开通会员”。价格先根据真实交付与支持成本测试，禁止虚构成交价、库存、限时倒计时与用户评价。图片/人脸/签名用于示例必须有展示及推广授权，退款与许可说明在购买前可读。

## 渠道分工与每周产出

小红书：主打纪念照/情侣名字画/摄影封面，一条图文6–8页：封面成品、原图对比、文字细节、三步操作、免费导出、适用与限制。每周2条，标题围绕真实用途如“把毕业照变成一句话组成的海报”；不靠夸大AI或盗用明星素材。依账号允许的方式引导站内检索/主页入口，外链和数字商品规则先核对。

抖音/视频号：每周2条15–35秒竖屏，0–2秒成品与原图切换；3–12秒选图片/输入短句/换风格；13–22秒放大字形/导出；最后一次明确行动。保持同素材、同标题意图，对比真实效果。付费工具DOU+/平台广告仅在账号获准、落地页/隐私完整、流量能归因后使用。

B站：每两周一条3–6分钟教程或开发展示：真实制作、中文/视频导出、保存与恢复、设备限制、授权来源。附带章节及可用帮助链接；适合设计师/独立开发者，转化到模板体验和定制案例，避免重复投放低信息短片。

公众号：每两周一篇案例拆解或模板教程，承担使用帮助、版本更新与售后；视频号与公众号互补，不一开始建设付费社群。文章的示例参数与当前正式版本一致。

搜索与官网：按使用意图建设字符画、名字画、毕业/节日海报和网页特效的实际教程页面；每周一篇，带可用例子/步骤/限制/免费入口。确保可索引内容、标题描述、canonical、sitemap、SPA搜索抓取；这些仍需工程实现，不写成已存在。不要批量生成重复空页。

设计/开发社区：两周一份可用效果展示和有许可的免费示例，提交到允许的社区/论坛；公开Demo展示结果，私有付费资产不随仓库发布。交流以具体技术与创作用途为主，不群发私信、不刷量。不自动发送站外消息。

个人运营每周约8–12小时假设：周一复盘1小时、周二制作案例2小时、周三录屏2小时、周四分平台改稿1小时、周五帮助与答疑1小时、周末试用访谈/分析1–3小时。以一份母素材衍生短视频/图文/教程，不照搬各平台标题与封面；忙时优先小红书+一个视频渠道，而非六平台同时日更。

## 90天顺序与退出条件

上线前两周：完成12个授权样例、三个免费模板帮助页、6条视频/6份图文库存、品牌头像/封面/简介、售后入口、交易真实状态与退款说明。邀请10–20位匹配用户完成真实创作，记首次成功/卡住位置/设备/时间，经同意才能录屏；关键数据丢失、付费权限绕过、错误收款/交付一票阻断收费。

第1–14天免费公测：每周2图文+2短视频；收集至少20次经同意的完整创作路径，优先修失败、卡顿与保存问题。CTA只指免费体验；先看“完成创作的人是否愿意分享/再次使用”，不能拿曝光代替价值。

第15–30天自然内容验证：三个意图各做4份内容，累计12份；每次只改封面/开头/用途一个因素，保持成品真实一致。按访问质量与成功创作比较，样本不足标记“不能判断”。邀请自愿试用者反馈一次，不追发骚扰消息。商业流程已全部验收才可测试一个有实际交付的SKU。

第31–60天小额投放：只挑自然内容表现稳定的两个用途/平台，先每组300–500元、三天总测试预算上限1000–2000元的假设；执行前由用户定预算与开户权限。一天检查落地页可用、扣费、支付/交付和异常；首次花费到预设上限暂停，禁止自动翻倍。支付链路或产品质量失败立即停广告并修复；不是把退款/差评用户排除统计。

第61–90天扩展：达成毛利与交付条件后逐周增加预算，每周不超过前一稳定周的1.2–1.3倍是假设风控上限，需实际批准预算；扩展第二类模板与2–3个小创作者合作。合作前确认受众、展示授权、真实制作、费用、披露、链接/邀请码、交付与复盘，不保底夸大转化。无真实利润或支持超载则回自然内容和产品修复。

## 内容脚本与资产清单

脚本A照片变文字：“这张普通照片，放大后每一笔都是你的短句。”真实前后画面2秒、上传与短句8秒、切两个可复现风格8秒、成品细节与保存6秒。行动“用自己的照片免费试一次”；不要写“点一下所有设备瞬间生成”。

脚本B纪念日：“把日期和名字放进同一张海报。”选授权照片、输入正向中文、调整对比、导出与打印示例；说明输出像素/打印尺寸关系，未实测印刷不宣称印刷认证。版权、人像及名字隐私告知。

脚本C品牌视觉：“一个指针，让文字像流体一样回弹。”展示真正正式效果和低性能回落，再展示嵌入范围/定制交付。行动指向案例与咨询，报价由范围和设备确定，不自动承诺固定工期。

每份资产保存原图授权、成品、可恢复项目、录屏母版、字幕、音乐许可、平台封面、文案、发布日期、渠道、落地页、版本、数据窗口。输出9:16视频、1:1/3:4图文、16:9教程；用户截图/评价使用需单独同意。已有output/astra-promo等只作候选，审核实际版本和权利后使用。

## 指标定义、归因与预算判断

漏斗分开统计合格访问、创作开始、成功导出、商品详情、订单创建、后端确认付款、权益发放、领取开始、退款成功及定制报价/成交；领取开始不等于完整收货。平台曝光与网站独立访问口径不同，不直接相除伪造转化。

内容加UTM source/medium/campaign/content（只含渠道/创意标识），落地页参数白名单；匿名创作指标需要隐私/同意/保留期实现，不上传照片、短句、签名、文件名、token或联系方式。付款/退款收入只能来自服务端账本，与去重订单匹配；会员/订单id不直接暴露到广告像素。当前埋点未实现，先受控访谈和人工记录，不能伪造报表。

日看技术异常与广告消耗；周看同一内容发布后7日的访问→创作→导出；月看成熟订单30日净收入/退款/支持成本。停投条件是交易故障、数据缺失无法归因、预算用尽、退款投诉显著上升或连续两个观察窗口贡献不足；小样本不用“0退款”等结论过度扩量。

贡献毛利 = 实收价−渠道手续费−税费−可变存储/邮件/计算−预计退款损失−每单支持成本。获客成本CAC = 同窗广告花费/新增有效付费用户数；重复购买不算新增，退款用户计入并另列净收入。试算39元成交、手续费假设1%、其他可变成本5元、退款准备3元、支持5元，则广告前贡献25.61元，广告CAC目标可先≤15元而非39元；这是算式示例，必须用签约费率/实际税费替换，不预测收入。不将未证实复购作为允许亏损理由。

## 如果需要直播推流

先在已获准账号测试每周一次30–45分钟“观众照片创作”直播；用户素材需明确同意展示，不保存未经授权的人像/联系信息。节目：5分钟成品与免费能力、15分钟真实制作、10分钟问题/保存恢复、5分钟总结入口；收款未开放不引导付款。

直播工具按平台提供的OBS/推流权限或官方伴侣使用；直播用当前产品录屏，不先建设自有音视频服务器/CDN。推流地址/密钥视为凭据，不入Git/聊天。开播前录制检查音画/字体可读性/网络/权限，安排审核与异常止播；获准后再考虑RTMP/HLS等自建直播及流量成本、合规与告警。自有直播平台不是首期部署必需。

## 每周复盘模板

记录日期范围/产品SHA/渠道权限/内容编号、实花费、真实访问与成功创作、有效付款及退款、TOP3失败与支持耗时、下周只改变什么、预算与负责人。产品问题进入研发阶段单独测试、文档、提交推送；推广方案定期更新真实反馈，不因一个爆款跳过质量/交易验收。
