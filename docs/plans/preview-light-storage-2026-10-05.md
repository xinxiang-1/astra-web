# 固定光色载体与真实Worker对照

接续[固定光色复用](./preview-light-material-2026-10-05.md)。此前缓存实际减少染色但中文耗时退化，本阶段验证把固定光色字形保存为原生OffscreenCanvas，是否比ImageBitmap稳定。新增surface载体、销毁时清空其实际尺寸；字形primitive、RGB、alpha、原生场、画序、64项主表和2MiB / 合计16MiB预算保持。没有修改生产 `src`。

## 实际方法

`research:preview-light-material`可设置 `ASTRA_LIGHT_MATERIAL_STORAGE=surface`；默认bitmap仍能重建。Edge / Chrome各六模式、透明 / 不透明和六个事件，共72帧及12个释放记录，surface与独立冻结原工厂RGBA逐通道零差，固定光色实际命中，销毁归零。

新增 `research:preview-light-storage`，分别独立打包原版、bitmap缓存及surface缓存三个实际生产协议Worker。每个请求都带新的indices / alpha / RGB数组，首条真实传入字形像素；每次Worker使用生产 `renderResponsive`、原8ms时间片与最终读回，不插入分段耗时拆解。固定180列、713px、原色 / 彩色中文及宽S轨迹，时间戳仍为33ms间隔和5秒释放。每帧轮换三侧顺序，Edge每模式三组独立Worker生命周期；Chrome一次补充交错对照，不伪称同样三组。

记录实际Worker完整结果、主表及光表预算、绘制进度次数和端到端完成时间。候选返回bitmap在页面读取RGBA，与同请求原Worker比较后立即关闭；QA自身像素读取可能影响后续GPU资源状态，所以墙钟结果仅是该上下文观测，不是实际鼠标或稳定FPS。它与上阶段同步renderer、带中间读回的拆解或真实页面首帧不能直接计算跨方法加速比。

## Edge结果与决定

以下P50 / P95来自每组中段六帧，线性插值 `(n-1)*p`；初帧、首个进入、释放单列在原始记录，未混入摘要。单位ms。

| 中文 / 2 | 10408 / 13110 | 10001 / 11752 | 10645 / 11180 |

原色三组缓存均有局部收益；surface没有稳定优于bitmap，中文P50又有退化。中文第0组 `inputFrame=8` 的原版 / bitmap为9509.6 / 8759.9ms，而surface为2223ms；释放后三侧都约9–10秒。随后新建Worker生命周期仍全部变慢，绘制进度次数由约38–53增至数百，三侧记录的主表仍64项、冻结主表157696字节、候选总187264字节、光表29568字节。因此这不是已证实的可见缓存越界，也不能把少数较好的尾帧解释为问题解决；未取得每个surface的后端证据，不宣称已证明软件后端切换或驱动故障。

Edge共180个实际Worker完成帧、120个候选与冻结RGBA对照，全部零差。像素与预算通过仍不足以满足商业性能，surface候选不接入生产，两种载体后续均停止相同方向的微调。保留原字形、颜色与分片反馈，下一步处理主字符的重复原生染色 / 提交成本，考虑通过共享场生成一次几何命令、集中绘制的独立路径；须先验证实际笔迹和输出合同。

Chrome补充一组每模式实际Worker交错对照，同样全部零差；共60个完成帧、40个候选与冻结对照。原色原版 / bitmap / surface的P50 / P95为12516 / 15846、9458 / 11459、7751 / 10166ms；中文为3935 / 4533、3028 / 3154、3043 / 3367ms。本组有收益但仍需数秒，且不能解释Edge的中文退化，也不能从两种浏览器的不同上下文反推出某一GPU后端已切换。最终双浏览器真实Worker共240个完成结果、160个候选配对零差，不宣称代表真实鼠标端到端或商业持续性能通过。
