# Astra 站点：风格与功能规划

> 目标：把橱窗式 Demo 收敛成「能讲清、能导航、能变现」的个人产品站。  
> 原则：**一个主产品 + 一个作品集**，账户体系后置。

---

## 1. 品牌与定位

| 项 | 定义 |
|----|------|
| 品牌名 | **Astra** |
| 一句话 | 本地优先的创意工具，外加可嵌入网页的实时视觉。 |
| 主记忆点 | **字符画**（中文铺字、可晒、纯前端） |
| 副记忆点 | **视觉工作室**（Prism 等 WebGPU/WebGL 特效） |
| 信任点 | 图片与文件默认在浏览器本地处理，不上传服务器 |

非目标（当前阶段）：特效 SaaS、作品广场、复杂会员体系。

---

## 2. 视觉风格（Design Language）

### 2.1 气质

- **精密仪器 × 夜空**：冷静、锐利、有空间感；不是娱乐向花哨，也不是企业后台灰板。
- **真视觉锚点**：首页英雄区用 Prism 全幅背景，不用抽象渐变冒充主视觉。
- **暗亮双主题**：同一套语言；落地页英雄区偏暗以衬托特效，工具页跟随主题 tokens。

### 2.2 字体

| 角色 | 字体 | 用途 |
|------|------|------|
| Display | Syne | 品牌名、区块标题 |
| Body | DM Sans | 正文、导航、控件 |

中文回落：PingFang SC / Microsoft YaHei（经 `--font`）。

### 2.3 色彩（CSS 变量）

| Token | 意图 |
|-------|------|
| `--bg` 亮 `#e9eef8` / 暗 `#070a12` | 冷纸蓝 / 深墨，避免奶油底 + 衬线套路 |
| `--accent` 钴蓝 | 主行动色 |
| `--accent-2` 青绿 | 第二渐变色，刻意避开「紫→靛」AI 模板感 |
| `--text` / `--text-muted` | 高对比正文 + 次要说明 |
| `--border` / `--radius-*` | 细边框；按钮可用 pill，内容区少用大圆角卡片堆叠 |

### 2.4 版式与动效

- **首屏只做一件事**：品牌 + 一句主张 + 一句支持文案 + 一组 CTA + 全幅 Prism。
- **分区一句一目的**：工具区 / 工作室区各自一个标题 + 一句说明。
- **默认不用卡片当装饰**：列表行、分区链接即可；交互控件才用面与边。
- **动效**：进入上浮、链接微位移、主题切换过渡；尊重 `prefers-reduced-motion`。

### 2.5 页面壳行为

| 类型 | 路由示例 | Topbar | 滚动 |
|------|----------|--------|------|
| 落地 | `/` | 半透明叠在英雄上 | 可滚 |
| 工具 | `/tools`、`/ascii-art`、文件预览 | 实心顶栏 | 可滚 |
| 沉浸特效 | `/studio` 下各特效页 | 渐隐叠层 | 锁定视口 |
| 账户 | `/login` 等 | 极简透明 | 按页 |

## 3. 功能分类（Information Architecture）

```text
Astra
├── 工具 Tools          ← 赚钱主线 / 用户带走结果
│   ├── 字符画          /ascii-art     ★ 主推 MVP
│   └── 文件预览        /file-upload → /file-preview
├── 工作室 Studio       ← 品牌与接单样板
│   ├── 目录            /studio
│   ├── Prism           /prism
│   ├── 黑洞            /black-hole
│   ├── 流体            /fluid
│   └── 彩烟            /webgl-fluid
└── 账户 Account        ← 壳保留，不主推
    ├── 登录 / 注册 / 找回
    └── 微信登录入口（占位）
```

### 3.1 工具（Tools）

| 功能 | 价值主张 | 阶段 |
|------|----------|------|
| 字符画 | 上传 → 本地成图 → 导出可晒 | **P0 变现楔子** |
| 文件预览 | 本地预览 Office / PDF | P2 流量配件，不抢主 CTA |

### 3.2 工作室（Studio）

| 特效 | 角色 |
|------|------|
| Prism | **可交付英雄背景**，工作室门面 |
| 黑洞 | 高辨识 Demo，科幻/科技向 |
| 流体 / 彩烟 | 氛围与互动彩蛋 |

工作室默认定位为展示与定制线索，不单独做订阅。

### 3.3 账户（Account）

- UI 壳可保留，文案降级。
- **有付费理由前不接真实后端**（字符画去水印 / 高级导出后再谈账号）。

## 4. 导航与首页结构

### 4.1 顶栏（全局）

顺序：`Astra` | **字符画** | **工具** | **工作室** | 主题 | 登录

- 「字符画」单独露出，强化主产品。
- 「工具 / 工作室」进分类页，避免顶栏堆 6+ 特效链接。

### 4.2 首页区块

1. **Hero**：Astra →「本地出片，网页会动」→ 支持句 → CTA「做一张字符画」+「逛工作室」
2. **工具**：主推字符画 + 文件预览一行列表
3. **工作室**：四个特效入口（Prism 优先）

不做：首屏塞统计、日程、多促销条；不做登录大区块抢视线。

## 5. 阶段路线（与变现对齐）

| 阶段 | 站点侧 | 产品侧 |
|------|--------|--------|
| **Now** | 分类清晰、风格统一、首页主推字符画 | Ascii 体验按 roadmap P0 |
| **Next** | 工作室页补「可嵌入 / 可定制」说明 | 水印 / 高清导出试收第一笔 |
| **Later** | 账户对接付费身份 | 模板包、接单落地页 |

详细字符画迭代见 [ascii-art-roadmap.md](./ascii-art-roadmap.md)。

---

## 6. 成功标准（站点层）

- 新访客 **5 秒内**知道 Astra 主推「字符画」，特效是工作室不是主产品。
- 顶栏不超过 **3 个内容入口**（字符画 / 工具 / 工作室）。
- 亮暗主题与特效页沉浸壳不互相打架。
- 去掉导航后，首屏仍能辨认是 Astra（品牌字号与 Prism 气质）。
