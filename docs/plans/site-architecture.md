# Astra 站点结构与视觉语言

更新于 2026-10-04。产品路线见[六方向计划](./commercial-quality-execution-2026-10-04.md)，实施见[公共界面统一记录](./site-shell-iteration-2026-10-04.md)。旧版“Prism 首页、Syne 标题、高清导出收费”规划已被当前字符画主站取代；历史内容保留在 Git。

## 内容结构

Astra 的主产品是由真实文字构成的图像与动态作品。案例、模板、帮助与本地项目围绕这条创作路径组织，工具页提供其它创作方式，视觉实验室提供网页光影。

| 区域 | 路径 | 职责 |
| --- | --- | --- |
| 主站 | /、/gallery、/templates、/help、/projects | 理解作品、选择模板、学习与继续创作 |
| 创作入口 | /tools | 字符画、循环字符、动态字符、签名画像、文件预览 |
| 工作台 | /ascii-art、/art-lab | 制作、调整、保存、免费输出，保留工作台自己的操作页头 |
| 实验室 | /studio 及四个效果路由 | 体验 Prism、黑洞、流体和彩烟，沉浸页保留公共导航 |
| 账户 | /login、/register、/forgot、/login/wechat | 统一品牌壳，真实服务状态另行验收 |

现有 PNG、透明 4K、TXT、视频、HTML、本地项目与 .astra 继续免费。商业方向为原创模板、新增创作能力和定制服务；真实支付、权益与交付单独按合同验收。

## 视觉语言

| 项目 | 约定 |
| --- | --- |
| 主色 | 纸白 #f5f3ef、墨绿 #111615、青色 #58e8ed |
| 亮色正文/链接 | #151918 / #087b82，保证阅读对比度 |
| 标题 | 共用 --art-serif / --font-display，中文宋体与衬线回退 |
| 正文 | DM Sans 与中文系统无衬线回退；外部样式表异步加载 |
| 内容层级 | 大标题、简短说明、主要动作；工具与实验室共用索引目录行 |
| 控件 | 共用按钮、主题、焦点轮廓；新增公共按钮与沉浸配置目标至少 44px |
| 作品 | 真实字符渲染，作品底色独立于界面主题 |

艺术主站保留纸色构图，工具、账户和公共控件使用亮暗 tokens；主题不重新着色作品。中文回退仍依赖操作系统，当前没有跨平台相同的本地正文字体包。

## 导航与交互

公共导航唯一数据源为 src/content/navigation.ts：作品、模板、创作工具、如何创作、实验室、我的项目。页头提供免费制作与登录，手机菜单补齐免费制作；账户页显示品牌、主题和返回首页。

- 宽度 ≤1180px 使用原生 disclosure，打开后 Tab 进入首个链接，Escape 关闭并还原焦点。
- 菜单外点击、路由与桌面宽度变化都会复位；短屏菜单与效果面板可滚动。
- 跳过导航聚焦主内容；页面切换更新标题与焦点，页面/首页锚点分别标识当前位置。
- 目录行保持点击区域稳定，仅移动装饰箭头；按钮光层随指针位置变化、离开消退。新增控件尊重减少动效。
- 作品交互继续遵守 [Studio 标准](./studio-effects-standard.md)。公共 CSS 改造不代表效果求解器、帧率或所有实验室引擎的减少动效合同已经升级。

首页三保护源及原 Studio 参数保持：ArtHomeView.vue、CharacterArtwork.vue、src/lib/ascii/studio-preview.ts；trail .65 / radius .38 / current .45。后续商业验收还包含自然签名画质、效果性能、输出与恢复、弱网、真实账户及交付服务。
