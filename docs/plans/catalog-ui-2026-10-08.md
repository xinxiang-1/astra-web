# 内容合集与购买前信息联调

2026-10-08，接续[已购领取](./purchased-delivery-2026-10-08.md)。本阶段接通公开商品信息与版本交付说明；订单创建、付款恢复、退款、会员和部署仍继续。

## 实施

新增 `/collections` 与 `/collections/:slug`，从免费模板和已购内容进入，沿用公共导航、主题、衬线标题、控件和页脚。目录读取后台公开列表，支持类型筛选、不透明游标追加、空目录、刷新和故障重试。合集详情显示后台商品名/简介、版本、整数分价格、引擎/作品包兼容信息、文件名/大小、交付清单及完整使用许可/购买条款/退款说明。ID保持字符串；切换SKU同时更新价格、文件和许可，使用文本渲染条款，HTML字符串不执行。

公开预览取后台允许的URL，no-referrer、懒加载；图片失败展示可读替代信息，不阻塞文件清单。不把免费模板或任意图片包装成正式付费商品。此阶段fixture公开预览复用原免费模板，仅验证URL/页面加载；正式商品原创内容、许可、预览质量尚待验收。

购买状态取后端capabilities。当前paymentEnabled固定false，页面明确显示购买未开放，没有订单/付款写入；capabilities故障时信息可读但购买状态待确认。未来开关变更也不能绕过尚未实现的完整购买入口，本阶段不提前启用生产交易。没有前端会员标志、价格授权或假同意条款复选框。浏览期间本地素材与项目不上传；已购下载仍由后端票据独立授权。

路由/筛选/刷新取消前次读取，新页面清除旧版本，迟到响应不得覆盖当前商品。内容503不会展示旧价格供操作；capabilities503独立处理，不把未知当可购买。页面提供免费模板、工作台、已购和目录恢复路径，当前主库无commerce迁移时显示受控故障，不注入固定假商品掩盖后台错误。

## 验证

相关type-check、ESLint、production build及真实浏览器/后台结果见[阶段证据](../validation/2026-10-08/catalog-ui/summary.json)。真实夹具使用独占MySQL schema与gateway，共用既有本机Redis且不停止该服务；浏览器匿名请求真实公开目录，不模拟auth/me，不提供JWT。空库和已发布商品分两次实际浏览器运行，包含免费模板创建、三页分页、类型切换、不同价格/许可的两个SKU、公开图片、503、迟到响应、键盘、390px主题和真实404。503与延迟明确由运输桥注入，正常数据/404来自真实服务。

最终R2相关全七模块verify成功，15项真实JUnit，0失败/错误/跳过，两组共12浏览器检查与32次真实gateway请求；合并193后台请求，共225实际HTTP/217商业schema通过。独占库及gateway清理验证成功，共享Redis保持；七个相关文件ESLint、type-check与production build通过。离线合同25操作/37fixture/17表/146既有链接通过，新阶段链接另查；首页三保护源无差异。未重跑全部不相关产品合同，不把本次指定测试集称为全站完整回归。

后台浏览器测试前后检查commerce_order/payment仍为零；第二版测试release/SKU/license仅临时加入独占库，随后精确删除，原目录/订单/模拟渠道合同继续验收。启用浏览器标志时证据要求15项真实JUnit和两组12浏览器检查，不能由默认跳过模式冒充。

## 失败与修复

R1空库与免费创作、已发布目录前七浏览器检查通过，返回列表时测试期待三项而超时。实际请求和DOM证明页面保留“模板合集”筛选，后台正确返回两项。修复为先断言两项及选中筛选，再主动切回“全部”并断言三项，然后继续迟到响应和404检查；没有改产品筛选规则或放宽实际数量。首次15JUnit有一失败的日志与未通过报告保留。

## 限制与接续

模拟视口不是实际手机/Safari验收，键盘仅验证选定入口；商品fixture不是真实上架内容，不能把接口连通当商业画质通过。真实支付仍关闭，会员尚未实现，不能把内容详情称为完整购买闭环。下一阶段继续本人订单详情/付款恢复与后端幂等，退款消费者/对账和生产渠道按[上线执行合同](../../../astra-cloud/docs/plans/launch-readiness-2026-10-08.md)推进；用户暂不需要购买服务器或申请商户。[推广方案](./growth-playbook-2026-10-08.md)随实际交付更新，不先投入收费推广。

本次构建与浏览器验证基于当前工作区，已有其它特效草稿保留且不混入本阶段提交；没有据此声称所有未提交草稿或正式发布产物通过验收。部署前仍需从明确Git版本做干净构建及完整发布检查。
