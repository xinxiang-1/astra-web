## 实际失败与修复

- Bing RSS反复给无关搜索结果，改官方文档/组织内检索；Adobe正文最初只截到导航，补抓关键词所在正文。图库401/403、StippleGen失败及字体raw请求失败如实保留，字体许可改用contents API成功取得。
- 本机 Playwright bundled Chromium 缺失，使用已安装 Microsoft Edge 154；未自动安装浏览器。TypeScript6明确要求命令行 `--ignoreConfig`，修正后候选严格检查通过。
- 合同最初将事件active=true与最终pointer.active=false放在同帧，等于每个移动都释放；修复harness保留最后真实状态，未改场或降低门槛。Canvas数值读回统一先创建willReadFrequently上下文，避免读回迁移影响精确配对；实际页面检查另用普通画布。
- 粒子残量归零后光强曾仍使用归零前距离，修复为清零后的距离。更重要的是滤镜光晕使透明面积栅格归位后仍有RGB约1级差异；零强度和宽度重置均不能消除，Chrome和Edge都复现。取消本候选的滤镜光晕，保留字符内部明暗，透明归位通过；没有放宽精确像素门槛，也没有改全局旧效果。
- 双幅对照的原生拖尾光层使真实输入期间完整帧约180～300ms、响应很弱；该失败保留。单幅候选真实鼠标检查通过，截图期间窗口P95约23.9ms（不是稳定30/60fps或跨设备P95认证）。默认单幅，仍可切并排对照且隐藏侧停止绘制；未降低列数、画布或原色精度。

## 验证与观察

[精简证据](../validation/2026-10-04/creative-research/README.md)保存合同/基线/视频/失败历史与实际截图；长记录和原始视频留本地。

- 20组独立渲染合同：六模式；density/color三品质，其余经典；透明/不透明。固定360px/64列、同瓷像、同事件轨迹。逐帧两实例最终RGBA确定性、原字符/RGB不变、零强度和自然归位逐像素相同；恢复最长约4.7秒模拟时间。状态最多129024 bytes，释放后归零。
- 恒定输入场的30/60Hz闭式弹簧偏移最大差 `1.4901161193847656e-8`；只证明此恒定力试验，不声称原生动态求解器任意帧率完全一致。
- 实际默认单幅720px/112列：鼠标有可辨识响应、归位、空闲300ms不重绘，减少动效偏移为零；390px无横向溢出，触控模拟1down/10move/1up/0cancel并正确释放。
- 12路由桌面与手机基线无页面运行异常/横向溢出。主产品使用art-header与Georgia/Noto Serif栈；tools/studio/signature仍用topbar与Syne，账户用DM Sans，确认确有两套风格。
- 名字画实测woven槽位下四分位墨量：Astra约7.46%、李云舟7.07%、张思雨8.72%、Alexander Montgomery2.64%、把名字写成光5.05%。仅这五组字体辅助、40写法、12度范围参考几何；它支持容量诊断，不代表任意笔迹不可实现高对比度。
- 开发视觉查看静态、快划与手机图：瓷像轮廓、字形和局部散开清晰，面部暂时让位于文字散开，衣肩保留主体锚点。属于助手研发检查，不是假装用户认可。
- `npm run type-check`、新增代码/脚本ESLint、候选严格tsc、`npm run build`全部退出0。构建仍有stream外置、大包和旧signature动态导入警告；本轮未声称修复它们。生产源码未改，原保护文件保持Git基线。
