# Astra 创作产品文档 v1.0

日期：2026-10-01。状态：基于现有源码与实际验证的首版实施基线，包含已实现、部分验证和待开发要求；不是全产品验收通过。负责人：Astra项目。前置：[总计划](./product-master-plan.md)、[品牌](./brand-identity.md)、[设计规则](./design-system-v2.md)。本轮变更与证据见[执行记录](./creation-product-iteration-2026-10-01.md)。

## 1. 问题、用户与目标

用户想将自己的图片、中文短句或短视频变成可以发布、继续修改的字符作品。当前主要困难是参数多、模式质量范围不同、保存与分享格式容易混淆、浏览器本地作品容易丢失；自然图片/中文/签名的商业质量仍需改善。

首批面向中文内容创作者、纪念照片用户、设计师。无需账户即可完成上传、预览、免费导出、本地保存与备份。产品目标是“从自己的素材完成一幅作品，并能可靠继续创作”；收入优先模板内容、新增付费创作便利与特效定制，不将已有免费4K/透明PNG/TXT/视频/HTML/作品包变为付费。

验证目标：用户任务测试观察首次上传到成功导出、保存后恢复、手机操作是否可理解。总计划80%完成率是待验证目标，没有真实用户样本时不得声称达成。

## 2. 范围与模块边界

首版覆盖 `/gallery` 风格案例、`/ascii-art` 编辑器、导出抽屉、`/projects` 本地项目、完整 `.astra` 备份；图片六模式、已有视频选段与离线HTML。签名画像与视觉工作室保持独立，分别验收质量/性能/交付。账户交易、云同步、公开社区、协作、云转码、订阅与批量创作为后续独立需求。

浏览器负责源文件、转换、预览、导出与本地存储。商业后端负责账户、商品/版本、订单/支付、权益与受控下载，不能用浏览器参数/本地许可文字作为权益证明。模板候选交付见[模板合同](./template-delivery-contract.md)。

## 3. 核心用户流程

访客从首页“免费制作”或案例进入；上传自己的素材，或使用明确来源的案例；选择模式、短句/颜色/清晰度；确认真实预览；选择免费成品格式并下载；按需保存本地项目或下载完整作品包。复访从项目页打开；换设备先导入作品包再继续编辑。没有支付或登录依赖。

应用案例时，有当前素材就只调整风格，替换素材必须有明确动作。模板包导入总是创建新项目，用户可以替换为自己的素材；原模板和已有项目不被覆盖。成品与备份入口各自明确：PNG/视频用于发布，HTML用于作品播放，TXT用于字符文本，`.astra`用于继续编辑并包含原始素材。

手机流程保持预览在前，“素材与预设 / 调整效果”切换面板，导出与保存入口可达；重计算、系统减少动效及不支持编码时提供实际状态/降级，不能让装饰遮住操作。

## 4. 需求与验收

### CR-001：图片输入与保留上一作品（部分实现）

当前识别PNG/JPEG/WebP/GIF/BMP/AVIF等浏览器可解码图片，普通上传不承诺全部格式；完整包只接受声明的位图类型。文件来源保持本地，失败提示允许重试。GIF作为图片输入不承诺逐帧动图导出。

必须：读取新文件前保留上一有效素材与已调整参数；解码失败/用户取消选择时维持原作品。仅在新素材可用后提交替换。明确尺寸/内存超限提示，避免浏览器失去响应。验收含坏文件、错误后重试、大尺寸、连续快速换图、取消与源文件释放。当前 `loadFile` catch调用resetAll，会清除已有作品，因此“失败不丢原作品”**待实现**；不能用已测错误提示/重新上传代替该要求。

### CR-002：六模式与品质范围（限定验证）

模式为光影字符(density)、原色字符(color)、中文铺字(phrase)、轮廓线稿(contour)、点阵细节(braille)、印刷网点(halftone)。新作品使用calibrated 2.2.0；旧项目保留legacy，用户明确选六模式才升级。文字顺序正向，无镜像或倒置。

默认经典保持；静态单色density可选精细/柔和/还原，静态color可选还原；视频与其他模式不启用未经验收的品质档。切模式不得悄悄抹掉用户输入的短句/颜色，质量不适用时显示原因并回到合法经典档。已有迁移/媒体合同和作品包十场景通过；自然照片、低对比中文和真实手写的商业观感仍待独立验收。

### CR-003：参数和快速调节（部分实现）

基础项优先模式、短句、清晰度、曝光/对比度、颜色、缩放；字格/字体/阈值等进入高级折叠。当前短句64个UTF-16代码单元，采样预设80/120/180/240/360列，自定义UI40–400列，转换兼容范围20–520列；不能将代码单元说成64个任意emoji。曝光-2到2，对比度-0.4到0.8，抖动0到1。模板/包按字段校验，不默默接收未知参数。

必须：快速调节只提交最新结果；旧异步解码/转换不可覆盖当前素材；计算中保留上次可见作品和可取消/重试状态，导出与保存仅捕获完整一致快照。当前有frameBusy/排队、缓存失效与生成快照，但跨来源竞态与中断边界**待专项测试/修复**。禁止直接通过全局CSS改变文字方向。

### CR-004：预览、全屏、动效与hover（限定验证）

六模式支持静态及光息/流动/聚合/慢流/重组/光斑，悬停支持光晕/涟漪/轻推/拖尾/水面/丝绸/漩涡/等高/溶解/关闭。新作品默认增强光影，缺效果风格字段的旧项目保持经典；选择新增效果显式启用增强。效果仅修改字符位置、透明度和字符产生的光影，不旋转/翻转字形、不改变中文顺序、不加入照片底图。

增强光影提供悬停强度0–1、范围0.05–1、微动速度0.2–2倍、强度0–1；经典原效果沿用历史公式，其范围/微动参数控件不显示。暂停冻结环境微动相位，悬停仍响应；悬停使用独立时钟，指针在画布外/离开/触控抬起或取消时渐隐。坐标按实际Canvas矩形计算，覆盖contain留白与全屏。离屏/隐藏停止调度，减少动效停用装饰；用户主动播放视频仍可播放。

预览、PNG与HTML基于同帧与字形；PNG保持静态，无鼠标状态。项目和作品包保存效果风格/速度/强度/范围，HTML内嵌这些参数并可在环境暂停时悬停；视频导出快照使用动效速度/强度。实施及本轮实际验证范围见[动效执行记录](./art-effects-iteration-2026-10-01.md)。真机稳定帧率、高列数与跨浏览器仍待验收。

首页原Studio拖尾强度.65、半径.38、慢流.45和hover为用户保护项，任何统一引擎或模板工作不得替换。官网其他区块滚动交互遵守品牌规则；首页首屏不新增滚动缩放/位移。

### CR-005：视频选段与媒体导出（部分实现）

当前上传MP4/WebM等实际可解码格式；默认目标15fps，UI可选12/15/20/24。实时播放按原cap降列，超清/高列数使用预渲染；选段最长20秒、480缓存帧与有界内存。显示当前时间/选段/解析进度，解析取消回到原时间。

作品包恢复必须同步片段起点、终点、长度控件与fps，暂停在起点；0.2–0.7秒真实H.264合同已验证。导出MP4优先，编码器不支持则WebM；不承诺保留音轨。长媒体、WebM无有限duration、Safari、精确端点与导出取消均**待专项验收**，不得以一秒样例认证全部媒体。

### CR-006：成品导出（限定验证）

保持PNG长边1080/2048/3840、透明背景、TXT、视频、HTML免费；文件名过滤非法路径字符，不执行标题内容。抽屉显示格式、尺寸、进度、错误与真实兼容限制；不支持视频时禁用视频格式。导出按钮防重复，失败后保留当前作品。

calibrated HTML内嵌字形与作品数据、无需CDN，视频输入64MiB上限且会包含完整源视频；legacy HTML明确说明需联网。TXT保留当前字符顺序，PNG与同设置静态帧逐像素一致；动态/编码视频用时间/选段和有损误差合同。已通过的六模式/品质档/真实媒体证据按对应轮次记录，跨浏览器与任意素材未认证。

### CR-007：本地保存、恢复、删除（限定验证）

IndexedDB保存id、name、kind、source File、thumbnail、settings、可选engineVersion；名称最大60个代码单元。当前保存是同ID更新，不是版本历史；新项目UUID。保存时捕获快照，过程中产生新调整仍显示未保存。清理浏览器数据会丢失本地项目，提示及时备份。

恢复源字节、参数、版本和模式；未知已记录引擎版本明确拒绝，旧无版本不伪造认证。删除前确认，取消不改变库；失败/配额不足显示可操作反馈。主流程与作品包导入已验证；浏览器清理/损坏旧数据库和设备配额仍待专项验收。

### CR-008：完整作品包（当前限定范围已通过）

当前`.astra` v1包含完整源字节、元数据、设置、引擎版本、缩略图；manifest与资产SHA256。源64MiB、缩略图2MiB、manifest64KiB。导入先结构/范围/完整性/实际解码，全通过后新ID单事务写入，重复导入不覆盖原项目。17类坏包和存储不足无写入已测试。已知不兼容版本拒绝，未版本化旧项目提示复核。字体文件与历史引擎程序不内嵌，不能保证跨设备逐像素相同。

### CR-009：未保存离开/新建提示（待实现）

在离开编辑器、路由切换项目/案例、刷新/关闭时识别未保存素材或参数。站内提供“继续编辑 / 放弃更改并离开 / 保存并离开”；保存失败保持当前编辑器和原目标，不能跳转。更换源文件也算更改；下载成品不等于保存可编辑项目。新建不会静默覆盖原项目。浏览器关闭只能使用原生beforeunload，不承诺移动系统强制关闭可拦截。

当前snapshot只含名称/参数，尚无导航guard或beforeunload；本需求必须独立实现并验证，不将文字状态“有未保存的更改”视为数据保留完成。

### CR-010：模板选择和交付（交付样品待验证，产品入口待开发）

案例与可购买模板分开命名；明确模板适合何种素材、修改内容、兼容版本与文件格式。导入可编辑包、替换素材、保留样式并免费导出。当前只有案例预设和作品包入口，没有模板商店/价格/权益。首个样品使用可追溯原创源文件；严格交付内容见模板合同。商品最终可售还需视觉、许可、价格、权益与售后验收。

### CR-011：移动端、键盘与可达性（部分验证）

390px不横向溢出；核心按钮至少44px，文字/状态可读；键盘可选择文件、模式、关闭抽屉和确认删除；focus-visible清晰，错误role=alert、进度/保存role=status。已测手机模式/导航/导出/作品包，未做完整读屏、色彩对比和真实手机性能认证。

## 5. 状态与失败处理

状态为无素材 → 读取素材 → 预览可用 → 有未保存更改 → 保存/导出/打包中 → 成功或失败；视频另有播放/暂停/预渲染/取消。作品/参数、源文件、转换generation、保存快照、导出快照要分别建模，不能仅用一个错误字符串推断全部状态。

无效输入保持上一有效作品；加载/下载失败可重试；存储不足保留文件/导出备份；版本不支持给明确信息；取消重计算/解析释放临时资源；离开保留提示不得与导出忙态冲突；离线HTML仅在实际没有网络依赖时称离线。上述尚未满足项以CR条目为准。

## 6. 保存字段与版本规则

项目settings当前包含editorEngine、artMode/artQuality/artMotion/artHover、artEffectProfile/artMotionSpeed/artMotionStrength、共享hoverStrength/hoverRadius、旧mode/hover/motion、phrase/阈值/填充/颜色、曝光/对比/归一化/抖动、清晰度/列数/字符集、反色/字号、预览与导出字体/字格、前景背景、选段与fps。项目运行态（鼠标、交互时钟、拖尾、进度、忙态、对象URL）不写入可移植包。

所有新增参数先定义类型/范围/默认值/不适用条件、包版本兼容与缓存失效，再写代码；未知新版本拒绝或显式迁移，不能默默丢弃。商业模板sku/version与用户本地项目id独立，退款撤销未来下载权益，不承诺追回已经下载的明文文件。

## 8. 分析事件与隐私

计划事件：creation_started、source_ready、mode_selected、preview_ready、export_started/succeeded/failed、project_saved、package_created/imported、template_applied。只记录合法必要的类别、耗时、结果和匿名错误码；不采集源图、视频、名字、用户短句、原文件名或文件hash。当前未接入遥测，不能把事件定义写成已有统计。

本地处理无需上传源素材；用户主动分享HTML/`.astra`时可能包含完整素材，应在入口/说明提醒内容。云同步、付款或咨询要独立说明服务器数据范围，不能沿用“所有数据不上传”。本地删除不影响用户已下载文件。

## 9. 依赖、风险与待决

依赖当前Vue/Canvas/WebCodecs/IndexedDB与系统字体、calibrated2.2.0和legacy兼容；SSR/云GPU不是本轮前置。艺术审美、许可、读屏、跨浏览器/手机、支付资质均未完成。模板价格/支持期限、部署地区、客服渠道与首批用户测试尚待真实业务决策，不使用虚构用户量或销量填补。

实施顺序：CR-001/003/009数据保留与导航 → 模板可编辑入口与帮助说明 → 真机/跨浏览器/视觉质量 → 创作验收 → 商业PRD/API/数据库 → 账户/交易/权益 → 免费公测与正式发布。自然手写商业质量继续为必需目标，不因样品抽象画通过而取消。
