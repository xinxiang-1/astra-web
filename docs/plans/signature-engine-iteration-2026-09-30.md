## 基线与素材

旧模块冻结在 `sandbox/signature-optimizer/baseline/engine/`。探索图为人像参考与 Aristotle 胸像，真实笔迹为 Benjamin Franklin 和鲁迅历史签名。官方 Commons 网页、Public domain 说明和 SHA256 保存在 fixtures；许可仅涵盖这两个历史签名。

旧算法没有考虑整段签名长宽，最低字号膨胀。768px、density=30 时约 18.5～18.9 万枚、15.8～19.7 秒，检测到所有签名均与邻近区域交叠。照片 underlay 已在上一轮移除，不再用照片掩盖画质。

## 隔离探索

v1 自适应四叉树减少碰撞，但字大小不均、层次不足，未直接采用。v2/v3 使用错行矩形区域，旋转和字号按完整 footprint 拟合，透明度补偿墨量，稳定 seed。

初始缩小密集纹理产生混叠，v3 评估改为真实区域像素平均，版本 `signature-box-tone-collision-v2`；旧 PNG 用同一新指标重算，未混用定义。

v3 纸白相关性约 0.834～0.979，夜光约 0.995～0.999；925～10,579 枚、67～306ms，检测区域碰撞为零。这仅为两个探索素材和 headless 桌面单次观察；不是 holdout、手机性能或商业美观证据。纯签名仍偏淡。

v1/v2/v3 保存 PNG、crop、参数、hash。v3 源码快照已补存并核对 woven SHA256 `08f49d5182b5f5b99b581fa950d87816077ea3d894233ec00a9631a2de6fa890` 与结果匹配。

复现：设置 `ASTRA_SIGNATURE_EXPERIMENT` 为新目录，`ASTRA_SIGNATURE_BASELINE` 为 `sandbox/signature-optimizer/experiments/2026-09-30-woven-v1/results.json`，运行 `node scripts/signature-layout-benchmark.mjs`。脚本校验浏览器、图片和基线源码，避免重跑昂贵基线，不覆盖旧轮次。

## 生产实现

默认 woven，保留 stipple；支持竖向排列和实际最大字号。最长边真实生成 4096/8192，采样上限 1024，只算布局不分配 8K 原照片。

纸白暗处密，夜光深底、亮处密、准确浅墨；自定义轮廓色优先。745 个轮廓位置的颜色回归通过。共享 RGB 规则、实际颜色缓存键、最多 64 栅格，SVG 继承外层 fill，空 trace 报错。

可选椭圆在 PNG/Path SVG 同步，默认关闭；分块和一次绘制排序一致。Worker 每请求独立，取消直接 terminate/reject，约 54～60ms；主线程回退无法保证及时取消。

多写法基准改为覆盖率下四分位，避免极淡模板压低全图。100 个字体变体概览 R 均值约 17.59→18.30，最大值 38→54；这说明对比度仍有限，不能宣传已解决。前后源码、截图、统计保存于 `2026-09-30-multi-writing/`。

## GPU 失败与门槛

原 LINEAR 图集缩小时笔迹破碎，纸白 MAE 0.08834、纸白填色 0.07553。独立纹理层/mipmaps 避免串色，子像素采样和过滤边界改善笔迹。探索自动/Canvas mip、整数 LOD、cubic、2×/4×场景平均、模板 mip 坐标仍未通过；复杂场景路径已撤回，探索源码和失败图在 `2026-09-30-gpu-investigation/` 留存。

最终候选：纸白 GPU MAE 0.02160，纸白填色 0.02288，夜光 0.00254，夜光填色 0.00356。纸白未满足 0.02，暗底全图误差小也不能证明笔迹正确。

最终局部诊断也已运行：8px、零旋转的 GPU 墨量仅约 Canvas 的 0.789，局部 MAE 0.02377；220px 墨量约 0.99988、MAE 0.00098。这进一步支持小尺寸采样未解决，诊断脚本退出 0 仅表示证据生成成功，不能算 GPU 质量通过。

**阈值未放宽，GPU 未默认启用。** `SIGNATURE_GPU_PREVIEW_VERIFIED=false`；官网走 Canvas。`allowUnverified` 只供实验。`npm run test:signature-gpu` 已实际退出 1，原因是纸白颜色/几何误差；JSON 记录 `gpuGate.passed=false`。晋升需相同门槛、局部笔迹和多模板真机验证。

## UI 失败与修复

手机 390px 被根 grid/控件自动最小宽度撑到约 670px。根列与手机列改 `minmax(0,1fr)`，面板允许收缩、顶栏换行，滚动画布限制在预览内。首页使用原艺术导航，hover 和动效保留。

早期 UI 检查只判断元数据/底色，遗漏空白；人工截图后发现全图 R=17。动态 replaceChildren 的画布与模板静态 ref 争用，重绘指向离开页面的旧 canvas。模板改为只维护容器，预览器管理画布。

回归增加实际笔迹像素检查。最终 602×551 夜光图有 39,229 个 R>20 像素、范围 16～54，手机无横向溢出。非空证明绘制正常，截图仍偏淡，商业画质未通过。

## 验证与成本

`test:signature-pipeline` 通过生产 Canvas、分块 MAE <0.004、SVG MAE <0.04、四底色填色组合、不含照片、确定性、空 trace、取消、实际 UI、自定义轮廓色和手机。分块 MAE 约 0.00100～0.00134，SVG 0.00312～0.02673；不是逐像素相等。

真实 PNG 写文件并重新 decode：3278×4096、16,110 枚、17,448,209 字节；6556×8192、42,632 枚、63,976,825 字节。栅格/编码约 1.2～2.2 秒 / 4.5～7.4 秒，随并行负载变化，不是移动性能保证。8K 画布本身约 205 MiB RGBA，另有缓存、编码和其他画布，需评估手机内存与下载。

通过严格 type-check、相关 ESLint、首页 Studio/暂停/滑块/减少动效/离屏/手机回归、上传/保存恢复/PNG/手机导航导出回归。构建保留既有 Office 大资源、stream 外置、无效动态 import、大包警告，不作为性能验收。GPU 检查明确失败。曾因首页脚本默认指向 5173 连接拒绝，设置实际 5180 后通过，非渲染回归。
