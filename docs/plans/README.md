最新产品交付：[完整可移植作品包](./project-package-iteration-2026-10-01.md)。免费 `.astra` 包含源素材、参数、缩略图与版本；编辑器可下载未保存作品，项目页可导入/下载，重复导入不覆盖原项目。开发/生产各10组图片恢复的真实PNG一致、17类非法包及存储不足无写入、旧项目/视频选段/390px入口通过；跨设备字体与跨浏览器仍待验收，模板商品授权、交易与部署尚未完成。实现说明见 [作品包格式](../../src/lib/art-project-package.md)。

签名生产接入轮次：[镂空排印、导出合同与生成快照](./signature-engine-iteration-2026-10-01.md)。生产默认 woven + 笔迹 + Canvas，新增可选镂空；100 写法、真实 4K/8K 和未应用调参导出回归通过。GPU 晋升失败并保持关闭，原笔迹严格 SVG 合同和商业画质待验收。

最新签名研究：[真实笔画碰撞与自然散布 ink-pack-v1](./signature-ink-pack-v1-iteration-2026-10-01.md)。两轮各40开发和24原生审计；R1低分辨率相交误判被独立核查否定，R2采用最终尺寸的双向笔迹账本，24场景最终上限通过。正笔迹不再依赖规则墨版，24场景对比原型、真实PNG与手机四宽通过；薄签名/暗部仍未形成通用合格画质，按两轮上限停止、不晋升，生产与最终来源保持。

签名前一研究：[真实墨量、面积提取与墨版边缘 native-v2](./signature-native-v2-iteration-2026-10-01.md)。两轮各48组开发和47/67项预检，两个墨版候选各8/8开发通过。接续完成16组预览/输出、8组真实4K/8K及39项API合同，仅修复沙箱柔边SVG静默改变风格的问题：柔边明确使用PNG，鲜明墨版保持路径SVG。旧输出hash保持，主站没有接入新候选；重复网格与局部采样仍未达到自然手写观感，最终3来源继续未消费。

编辑器前一轮次：[六模式、统一帧与离线媒体合同](./art-editor-iteration-2026-10-01.md)。新作品默认 calibrated + Canvas，旧项目保留 legacy；六模式 PNG/TXT/HTML、视频预渲染/编码、本地恢复和实际生产导出验证。自然照片商业观感、真机、精确剪辑仍待验收；完整作品包进展见最新产品交付。

上一画质与性能轮次：[自然照片验收与缓存修复](./art-quality-iteration-2026-10-01.md)。画质候选在新 holdout 的细纹理门槛失败，保持隔离；生产仅修复保持原像素的 Canvas 字形缓存，并保留默认、首页与失败证据。

画质前一轮次：[自然纹理与中文墨量 quality-v4](./art-quality-v4-iteration-2026-10-01.md)。216 组开发筛选后，仅静态单色光影字符的高质量过滤/两倍采样通过唯一新 holdout，接入可选「精细 / 柔和」。经典默认与首页原动效保持；中文、彩色及 30 fps 未通过，新档的开发/生产 4K/全屏/离线 HTML/恢复已验证。

继续迭代：[中文光学字格与软件颜色合成 quality-v5](./art-quality-v5-iteration-2026-10-01.md)。两轮各288组与80工程合同后，软件 density/color 通过唯一15组新 holdout 中的6组候选；生产2.2.0增加图片「还原」档。中文仍在低对比来源失败，光学字格保持隔离；生产迁移192项和默认/排除场景30组通过，实际媒体与生产构建验收详见轮次记录。

前一中文轮次：[横纵留白、自然排版与墨量拟合 quality-v6](./art-quality-v6-iteration-2026-10-01.md)。两轮各120组主句与150组扩展检查；自然宽度改善混排/标点，但四档扩展仍有49个候选失败，按两轮上限停止且未晋升。

最新中文轮次：[跨尺度重建、容量诊断与字号排印 quality-v7](./art-quality-v7-iteration-2026-10-01.md)。两轮各96组主句与240组扩展，45项物理容量诊断；R2通过557项工程预检，但四个新字号档扩展共70个失败，原生视觉存在稀疏字/标点尺寸节奏问题。按两轮上限停止，不晋升；生产2.2.0、主页原动效/hover与免费导出保持，三个最终源未消费。用户明确指定的六份文字记录为参考，不使用v1原型图片替代偏好依据。
