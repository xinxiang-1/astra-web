# 高密度绘制拆解与区域缓存对照

接续[空闲调度与生成提示](./preview-feedback-idle-2026-10-05.md)。上一阶段消除了无用请求，本阶段测量实际完整帧成本，并验证独立的静态画面/局部重绘候选。生产工厂、编辑器、原生场、首页和已认可的按钮均保持 `92bc304` 的实现；本阶段没有把候选接入生产。

## 耗时拆解与假设

冻结同一瓷像、180 列、713px 长边、实际 OffscreenCanvas、原 64 个临时彩色图块。Chrome 154.0.8037.57 与 Edge 154.0.4258.53 各检查六模式、light/particles 的三个输入帧。独立生成的工厂在场、主字符绘制、光层之间读回 1 像素以排空 GPU，分开观察成本；这些额外读回会改变批处理，不能当实际 UI 帧率或与后续配对测量直接计算加速比。

实际结果中，Chrome 原色主字符绘制约 1.0–2.6 秒，中文主字符绘制约 1.9–4.6 秒；最后光晕帧的光层约 0.80/1.82 秒，而光晕场计算小于 1ms。最后聚散场约 45–59ms。Edge 的对应主绘制/光层较快，但同样以绘制为主。真实 glyph 中，原色有 10,800 个半透明、649 个不透明字符；中文有 9,113 个半透明字符，不能直接在静态图上再次叠加文字而宣称 alpha 一致。

候选保存完整静态主绘制，逐格精确检查字形、位移、大小、强度和 opacity 是否改变，合并改变字格的旧/新边界。面积小于 80% 时重画该区域，广泛变化继续完整绘制；不忽略小信号、不改变场、不量化颜色。单份静态画面与 indices/alpha/RGB 快照合计上限 16MiB，实际比较完整数组内容，支持 Worker 每次 structured clone 后的相同作品，同时避免仅依赖对象身份。候选只研究静态环境、普通 Canvas 栅格；柔和双倍栅格和软件面积路径继续原路径，尚未验收候选的全品质合同。

## 实际失败与修正

- R1 使用整数矩形 clip 裁剪原生字形绘制，144 帧中 142 帧零差；中文聚散的一帧不透明有 35 个通道变化、最大差 1，透明有 79 个通道变化、最大差 6。保留失败并拒绝该路径。
- R2 的假设是避免裁剪字形 primitive：完整绘制相交字形，再恢复区域外的静态像素。第一版对子矩形使用 `copy`，错误清除了整个 clip 内的其它目标像素，六模式都有大幅差异。这是实现错误，原报告/diff 保留。
- 修正为一个由区域外整数矩形组成的 clip，只在复制完整缓存画面时关闭平滑；原生字形 primitive 始终完整，原排序及着色不变。两浏览器各 144 帧的六模式、透明/不透明、light/particles、移动/释放/长间隔均 RGBA 零差，连透明 RGB 也比较。
- 真实 Worker 通过原生产协议接收连续五个中文聚散帧，相同作品的 typed arrays 确实被 structured clone；缓存 hit/patch 都实际发生，完成 bitmap 与冻结工厂逐像素一致。Chrome 的完整最终流程与 Edge 流程分别保留，没有把直接 OffscreenCanvas 对照冒充页面操作。

## 配对成本与决定

两个浏览器分别测原色和中文、light/particles；180 列、同素材、713px 长边，逐帧交替两侧先后顺序，每次新建源数组，完成后读回排空 GPU。每组只有六个连续输入帧，用线性插值 `(n-1)*p` 计算 P50/P95；原始报告的早期索引式摘要保留，以下来自[原始逐帧数据重算](../validation/2026-10-05/preview-region-cache/paired-summary.json)。另有初帧、首个进入帧和释放帧，未混入这六帧统计；每组聚散实际 peak 超过 `.005`。事件时间为固定合同轨迹，成本是独立 renderer 墙钟测量，不是实际鼠标操作端到端延迟。

| 浏览器 / 模式 / hover | 冻结 P50/P95 ms | 候选 P50/P95 ms |
| --- | ---: | ---: |
| Chrome / 原色 / 光晕 | 1905 / 2070 | 1927 / 2169 |
| Chrome / 原色 / 聚散 | 1182 / 1675 | 1172 / 1253 |
| Chrome / 中文 / 光晕 | 4637 / 5033 | 4237 / 8560 |
| Chrome / 中文 / 聚散 | 1986 / 2253 | 1351 / 1664 |
| Edge / 原色 / 光晕 | 856 / 894 | 850 / 883 |
| Edge / 原色 / 聚散 | 586 / 805 | 376 / 608 |
| Edge / 中文 / 光晕 | 1654 / 1850 | 1930 / 2010 |
| Edge / 中文 / 聚散 | 913 / 987 | 576 / 840 |

独立小范围聚散有收益，中文聚散两浏览器这组 P50 约减少 32%/37%；Chrome 原色 P50 几乎未变。光晕高斯信号会改变大量半透明字格，本组需要重绘约 94%–100% 的主体区域，矩形缓存几乎不能帮助主绘制，且出现更慢的长帧。六个样本不足以证明稳定统计或商业性能；像素通过也不等于整体速度通过。因此不把该通用候选整体接入生产，不借局部加速宣传光晕、其它品质、手机、4K 或视频已实时。

[证据目录](../validation/2026-10-05/preview-region-cache/README.md)包含分阶段耗时、失败、最终逐像素/Worker、逐帧成本、可恢复生成 diff 和 hash。`npm run research:preview-profile` 与 `npm run research:preview-region` 可从冻结提交重建；第二条默认 R2，`ASTRA_REGION_REVISION=r1` 重现旧几何失败，`ASTRA_REGION_PARITY_ONLY=1` 只验像素/Worker，`ASTRA_REGION_BUILD_ONLY=1` 只生成源码。脚本 ESLint、Node 语法、文档链接及重建 hash 检查通过。仅研究脚本、npm 入口及文档有变更，本阶段未重跑或声称生产 type-check/build/UI 验收。
