## 本阶段实际接入

1. 签名笔迹支持自动墨色、自定义 RGB、原图位置颜色；浓度 0.2–3，1 保持旧效果。250ms 合并输入后沿现有可取消、完整快照流程更新预览，PNG、路径 SVG、作品文件消费同一 placements。补齐历史 stipple 布局忽略自定义墨色的问题。原图取色按每枚签名所在的区域平均，图片不作为笔迹覆盖层。
2. 支持的单色光影/原色图片新作品与重置默认“还原”；切回支持模式时恢复该默认。旧项目的已有品质保留，视频、中文及其它不适用品质的模式仍按既有合同。编辑器移除“光晕”，默认拖尾；旧光晕项目恢复时关闭该悬停，旧格式/历史 HTML 仍可读取。首页和原 Studio 参数保持。
3. 三个可微调配方使用已有统一引擎：流体揭幕（轨道入场+撕裂试用）、字符绽放（片层重组+聚散试用）、全息显影（光迹扫描+拖尾）。配方不替换源素材/文字；实际参数保存，不增加只有名字的伪引擎。撕裂/聚散仍属试用。
4. 签名页“继续创作”由当前完整作品生成最长边不超过2048像素的 PNG 副本，将原色/还原/配方参数保存到现有 IndexedDB 字符项目，再由用户在新标签页打开。当前签名页面保留；派生项目进入 /projects，可继续调参与免费导出。原签名要另存 `.astra-signature`，图片副本不能还原成原笔迹布局。当前不提供统一双工具工作流包、云同步或多人协作。
5. 彩烟开发故障明确定位：两个 Vite 服务与 SSR 合同共用 `.vite`，webgl-fluid 优化依赖返回504 Outdated Optimize Dep。缓存按 command/mode/port 分开，预优化依赖；实际5173重启恢复，两浏览器打开成功。增加加载状态、友好错误、重新加载与离页后的异步创建防护。未声称改写第三方循环销毁。

## 创作生态应如何继续闭环

输入原照片与有授权的真实手写 → 名字库/字形资产 → 完整签名作品 → 色彩/构图变体 → 字符派生作品与配方 → 参数版本与可携带项目 → 图片、矢量、HTML、视频 → 原创案例/模板交付 → 后台订单、权益与私有内容。每一环都要能取消、保留上一个完整作品、明确文件用途并恢复。

目前字符项目有统一列表、签名有可携带文件与名字库，跨工具仅打通图片派生。下一步统一作品索引时保存 kind、原作 id、派生 id、缩略图、recipeVersion、engineVersion 与 source SHA；不在字符串备注中假装已有依赖图。跨设备包需要同时携带两种原项目及 manifest，校验资产/版本/许可证并防重复导入，先在本地验证，再评估云价值。

变体先支持非破坏性比较：同一签名几何，比较单墨/照片彩墨/夜色与不同墨量，选定后冻结输出。批量需要逐个快照、可取消队列、内存预算和失败恢复；不把并发开数十个 Worker 当加速。传播交付提供横/竖/方三种构图样例，原始签名文件与派生项目一起备份；当前无自动批量或工作流包上线。

## 网上来源与取舍

2026-10-09 已联网阅读以下作者/官方来源；只记录简要归纳与本项目推论，不复制整篇教程。联网发现不等于已经集成。更详细的取舍与原型规格见[研究清单](../research/2026-10-09-creative-ecosystem/README.md)。

- [Edoardo Lunardi：Shape-Aware ASCII，2026-09-04](https://tympanus.net/codrops/2026/09/04/beyond-the-luminance-ramp-a-shape-aware-ascii-renderer-in-three-js/)：单格内部形状/邻域与字形 atlas 匹配，有利于斜线和边缘。建议隔离比较现有“还原”与形状候选，保持列数/字体/源图；不能只提高密度或把95字形案例外推中文。
- [Pablo Stanley：Efecto，2026-01-04](https://tympanus.net/codrops/2026/01/04/efecto-building-real-time-ascii-and-dithering-effects-with-webgl-shaders/)：实时算法比较及材质输出。Astra 候选为有限色彩、版画/网点配方；已有 halftone 不重复命名为全新模式。
- [textmode.js 分层](https://code.textmode.art/docs/layers-and-compositing)、[过滤](https://code.textmode.art/docs/filters)、[导出](https://code.textmode.art/docs/exporting.html)：学习分层组合与输出事实范围。其文本/矢量层数据与最终画布捕获不同；Astra 不能承诺 TXT 重现视觉光效，也不能称当前 MP4 已录制真实悬停路径。
- [p5.asciify 自定义转换](https://p5.textmode.art/docs/guides/custom-ascii-conversion/)：每格字形、颜色与 renderer 管线。优先复用 Astra 当前六模式与统一场，不直接引入另一套不一致的绘制/导出。
- [Tyler Hobbs：Flow Fields，2020-02-03](https://www.tylerxhobbs.com/words/flow-fields)：连续方向与流线构图。Astra 已有签名 flow 方向；下一轮研究照片结构引导、相交约束与留白，不把旋转签名当新增能力。
- [Lolo Armdz：交互文字破坏，2025-07-22](https://tympanus.net/codrops/2025/07/22/interactive-text-destruction-with-three-js-webgpu-and-tsl/)：恢复基准位置和弹簧阻尼的交互。已存在字符聚散，后续候选应验证墨片边缘/分层深度，不抄整套3D字体或另添通用爆炸按钮。
- [Vivus 官方](https://github.com/maxwellito/vivus)：SVG stroke 依路径顺序绘制。现有 trace 是填充轮廓，没有真实书写顺序；可研究“笔迹显影”，真实重写必须采集中心线/时间/压力。其 MIT 许可已阅读；本阶段未引入代码。
- [Codrops 许可](https://tympanus.net/codrops/licensing/)：下载 demos 默认MIT且有例外，设计 freebies 禁止转售/重分发；文章、照片、字体及第三方依赖各自检查。不能把网站案例包装为原创付费模板。

## 自动执行与晋升标准

每个候选执行：核实一手来源/版本/许可 → 判断已有能力是否重复 → 写单一问题与可证伪验收 → 同素材可操作原型 → 工程与完整动态视觉检查 → 必要修复 → 达标才接正式项目/输出 → 更新文档 → 独立提交立即推送 → 官方 GitHub 核验。失败、环境问题和未过审候选保留，最多两轮设计验证后明确取舍，不无限自我抛光。

共用[Studio 标准](./studio-effects-standard.md)：慢拖/快速S/绕圈/停止/离开复原，真实时间与合并事件，六模式/适用品质，触控/减少动效/暂停/隐藏/全屏，HTML/项目/静态/视频合同。高密度原色仍可能慢，真实吞吐与设备范围要测量。技术通过不能宣称用户审美或收费品质通过。

## 当前验证与明确边界

双浏览器各7个核心合同与7个生产操作：墨量单调、1×兼容、两布局的几何/RGB/浓度、签名项目恢复、有限尺寸 PNG 的 Worker 失败回退与禁止放大、三配方 .astra 往返；生产自定义颜色/恢复、连续浓度输入、照片区域色、跨工具保存/打开/改配方和新作品/重置“还原”。另有 Edge 390×844 触控模拟8项，含两页/新控件边界与真实点击入口。最终320px工程样本自动调色约0.42–0.46秒，创建派生项目约0.13–0.15秒；不能外推4K手写照片或真机性能。
