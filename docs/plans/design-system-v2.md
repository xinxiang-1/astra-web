# Astra 设计规则 v2 — 创作基线

2026-10-01。状态：当前主产品的实施规则与待统一清单，尚未完成全站/真机/用户评审。依据实际 `art-system.css`、`art-editor.css` 和[品牌](./brand-identity.md)，不是另起风格。首页原动效/hover是保护项。

## 1. 视觉与内容

暗色用于首页/作品展示/编辑舞台：#111615；页面与参数面板用暖纸白#f5f3ef；正文墨色#151918；主要行动青色#58e8ed；浅色辅助强调采用深青#078c91；分隔#dddcd5。主产品优先中文，少量英文用于小型品牌标记，重要操作/错误不能只写英文。

Logo使用已接入的原创路径A/星芒，不替换字标、不拉伸；中文标题延续Georgia/Noto Serif SC/Songti/SimSun回退，正文继承font-body，数字辅助等宽。系统字体差异实际验证，不承诺所有设备同字形。字号层级：页面标题桌面约48–60px、手机36–40px；编辑器区标题18–23px；按钮/正文12–14px；说明最小11px目标，现有部分10px/低对比提示列为待改善。色彩对比需实际检查，不把tokens本身视为WCAG认证。

## 2. 布局和组件

内容页art-wrap最大1440px、桌面左右56px；手机左右间距沿现有断点。编辑器桌面素材/舞台/参数三区，1150px收窄、800px切上下，手机先预览后面板。页面间共享导航、页脚、Astra Logo，账户/工作室旧语言逐步统一。

主按钮圆角40px、最小46px高度；触控操作至少44px；只有关键行动使用青色，次要按钮墨色边框/文字。项目卡片展示真实缩略图、名字、类型/时间、可编辑打开、下载包与删除确认；不显示虚构社区数据。输入有清晰标签、错误不只靠颜色，文件选择原生控件由可聚焦的设计按钮触发。抽屉/确认对话框防重复提交，关闭后焦点回到触发按钮。

状态统一中文：正在读取素材、正在生成预览、已保存到此浏览器、有未保存的更改、正在打包原始素材、导入成功。说明准确区分本地保存/成品导出/完整作品包。错误给原因与下一动作，忙态禁止冲突操作，不用成功toast掩盖未写入。

## 3. 动效规则与保护

2026-10-02用户确认：以后艺术特效以原生 Studio 引擎为底座与验收基准，在统一六模式引擎上创新。拖尾须具备真实速度注入、连续平流/卷动和局部密度变化；水面/丝绸/漩涡等须有持久交互场、跟手和自然余波。不能只沿用名称、加圆形亮斑或依靠CSS滤镜。字符保持正向，创新效果须兼顾可读轮廓、暂停、免费输出和离线恢复。首页主图仍是保护项；新效果先做与首页/原生Studio的实际轨迹对照，记录原生数值一致性、实际像素和性能，再进入产品。实现与下一轮创新方向见[Studio交互标准](./studio-effects-standard.md)。

首页原Studio拖尾.65/.38、慢流.45保持；不对首页首屏新增滚动缩放/位移。文字水平正向，hover只允许既定颜色/轻位移；Logo只星芒/横梁受其完整作用域影响。其他区块可滚动入场和模式交互，持续特效必须暂停、离屏停止、标签页隐藏停止、减少动效、移动降级。

控件120–220ms、区块300–600ms为目标区间；不劫持滚动、不把多个重画布无约束同时运行。艺术模式动效由真实引擎参数产生，不能用CSS滤镜冒充画质升级。实验页标注范围与不足，保留实际原图对比。
