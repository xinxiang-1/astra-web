# 字符画像的视觉风格与校园礼品适配

检索日期：2026-10-06。这里的“画质”按用户语境解释为视觉风格；2K/4K/8K、抗锯齿、缩放清晰度是另一组质量设置。网上没有公认的风格总数，风格可以交叉组合。以下是为了本项目整理的**18个方向**，不是“全网恰好18种”，也不是大学生销量排名。

## 先解决实际偏淡

用户提供768×1024原图及6144×8192签名PNG。对成图每8像素取样（768×1024样本），近纸白定义为RGB各通道与主底色(245,243,239)差不超过2：全图约45.25%接近纸白，选定头发区43.03%。同一头发区域sRGB加权平均亮度由原图52.45变成194.33，脸颊161.12→233.38。这是文件数值诊断，不是打印测量，也不能由这些统计反推出每枚名字的alpha或真实笔迹面积。

原生裁片显示完整深色小名字之间有大量空白。平均颜色近似 `C=(1−coverage×alpha)×paper+coverage×alpha×ink`；alpha≤1，即使把墨色设为黑，低覆盖率仍达不到原图深色。因此继续加浓度或提8K不能保证浓郁。颜色还受到局部采样、笔迹alpha与纸白共同影响。

用户明确选择接受彩绘底色＋完整签名。本轮新增“浓彩融合”：照片降采样至最长384px，只承载大面积颜色；默认75%叠在作品底色上，再按既有Placement绘制完整签名。底色可调10–85%，选择纯签名即为0。它有实际图像层，UI与SVG均明确说明；不能宣传为每个像素只由名字组成。新的纯手写密排、负墨版审美及旧停止实验没有重新包装上线。

“已有”指有对应引擎基础，不等于整个风格已完整商业验收；“开发”指下面的算法方案，尚无正式预设；“辅助”需要人工版式或AI/人工源图处理。适配与场景是本项目的设计判断。

## 第一批建议做六套

1. **浓彩名字纪念**：先落实本轮偏淡问题，提供纯签名/融合对照；原色、暖纸、深夜三套配色。
2. **双色校园海报**：两色/三色有清楚辨识度，用学院或社团颜色，避免同一RGB只换滑块名字。
3. **Riso文艺印刷**：蓝红/绿粉/黑橙；套色位移按成图毫米约束，不镜像、不打乱中文。
4. **波普生日礼物**：分区色面＋边缘＋姓名/日期版式，优先人物识别与肤色，不盲目增加饱和。
5. **国风名字画**：中文完整签名沿轮廓，留白和构图成为审美；不把字体辅助称真人手写。
6. **像素游戏画像**：调色板和粗网格形成真正不同风格；长名字留在主要构图/署名，不硬塞进8px小格。

线稿和经典黑白继续作为简洁选择；霓虹适合数字展示，打印中发光表现只是颜色与对比，应做实物打样后销售。

本轮另用用户同一张照片生成了六幅实际字符样例：黑白、中文、双色、网点、轮廓和像素。`scripts/render-portrait-styleboard.mjs`可复现，默认使用仓库公开示例；指定私人源图时，图像、可点开放大的HTML及拼版仅写本地ignored test-results。它不改引擎或正式预设。人工查看发现中文暗底整体偏暗、轮廓细线偏淡、像素字格边界明显，故只作为方向对照，**未当作六套商业模板上线**。双色是单条双色插值映射的初步样例，完整双墨曲线系统仍属于后续开发。

2026-10-07接续[三种字符印刷候选](../../plans/portrait-print-styles-2026-10-07.md)：双色已做独立墨曲线；Riso为有限墨色/真实字形screen/确定纹理与有界套色；波普为保边平滑/分级色面/关键轮廓。独立页面支持同素材三幅对照、配色/中文/1K与2K、后台进度/取消、原大缩放及PNG。仍在研究页，格纹、中文墨量和实体打样未完成，不把这次称为三个正式商业风格或完整手写签名风格。

## 关键算法拆解

2026-10-07接续[签名融合配色](../../plans/signature-wash-styles-2026-10-07.md)：双色与波普先做同一完整Placement的1K/2K对照，随后以试用底色配方接入签名编辑器，贯通PNG/SVG/项目/高清区域。新底色明确是图像层，完整名字和原墨色保持；没有把它当纯字形Riso或商业审美已通过。

- **双色**：从线性RGB亮度Y或明确约定的sRGB亮度生成阴影/中间调两条独立墨曲线 `a1(Y),a2(Y)`，以纸色合成。双色不是简单把所有亮像素染同一种颜色；保留眼睛/嘴角的局部对比。每枚完整签名可以承载一个墨层，预览与输出要保存相同色板/曲线。
- **Riso**：分色得到2–3个有限墨层；网点用 `r=cell×sqrt(t/π)` 或字符实际alpha面积匹配目标墨量，组合以明确的减色近似处理。可增加固定种子的稀疏纸纹与少量套色偏移；纸纹不得淹没名字，偏移不改变阅读方向。数字模拟不能承诺与真实Riso墨色完全相同。
- **漫画**：先保边去噪/双边近似，降低照片高频噪声；3–5级量化形成大色面，梯度阈值保留人物关键轮廓。字符/签名只在限定色面内铺排。只有色彩量化、没有构图和轮廓，不足以称成熟漫画风格。
- **版画/线稿**：用梯度场及邻域结构张量获得稳定方向；低置信度区域保留自然水平名。正向角度有界、签名完整，再以密度而非持续透明控制明暗。过密会相交，要以真实笔迹而非包围盒审计。
- **像素**：先把源图面积采样到有限网格，再按感知色差量化色板；抖动误差有界、种子固定。画格填充由高覆盖字符完成，而不是缩小高清照片再放大。网格降低是风格选择，不自动提高源图细节。
- **浓彩融合**：`base=(1−s)×paper+s×wash`，然后 `out=(1−a)×base+a×ink`；wash只来自生成时的那份原图，a与每枚Placement固定。透明源图保留其alpha。0强度严格走纯签名旧路径；未应用新参数时导出仍消费旧快照。

## 验证是否更容易购买

先用同一套获授权照片做六种真正不同的风格，不混用模特、分辨率和价格。找愿意试看的学生做自愿匿名排序：第一眼识别、近看名字、愿意送谁、愿意支付多少。人数与学校覆盖如实记录；小样本只作早期筛选。将“喜欢/收藏”与实际下单、付费、退款分开统计。

首批以生日/情侣、毕业/师生、社团/游戏三类场景组织入口，不预先把全部用户按性别贴标签。商品差异放在成套构图、可编辑信息、印刷与服务；现有PNG、SVG、项目等免费导出保持。下一阶段先做同素材六风格对照和纸上打样，再决定正式预设，不一次加18个未经验证的按钮。
