# 创作高级玩法：下一轮实验清单

资料核验日期2026-10-09；[阶段与一手来源](../../plans/creative-ecosystem-2026-10-09.md)。以下均为候选规格，只有阶段记录标为接入的能力才属于正式产品。

## 先执行：形状匹配与笔迹显影

形状候选对照现有还原，不改字体/列数/尺寸/曝光；从实际字形遮罩提取局部覆盖和方向，以有限权重结合明暗误差。先检查斜线/十字/弧线、头发和建筑边缘，再看平滑肤色；边缘改善但肤色变花不晋升。测试144/180列、同设备耗时、TXT字序和透明输出，中文铺字先排除任意字形重排。不要重跑冻结旧holdout或降低其门槛，使用新的许可素材并标训练/开发/审美留出。

签名显影先在真实完整 placements 和印章 alpha 上做顺序遮罩，提供播放/暂停/拖动进度/减少动效；最后一帧逐像素还原当前作品。顺序可按轮廓、中心至边缘或明暗，但明确叫显影而非真实重写。中心线书写版必须保存点、压力、时间、pen-up，校验SVG/视频重放；轮廓描边不能替代。

## 接续：结构流场与分层墨片

照片梯度引导签名方向和疏密，限制角度、签名完整性和名字阅读；与现有 flow 同源图比较留白、笔迹碰撞、暗部和眼鼻细节。保留种子与全部参数，不仅比较总相关性。新分层交互使用现有只读真实速度/密度场、签名原始纹理/颜色与回弹，不引入随机彩点。鼠标停住后不持续破坏，快速路径连续，触控释放可恢复。

## 后置：动作剧本与工作流包

确定的片头→显影→停留→交互→循环可以成为配方时间线；手势轨迹含规范化坐标、时间、强度、事件类型与引擎版本。先用固定轨迹验证预览/HTML/视频一致，然后才叫“动作录制”。当前环境 MP4 不具备该能力。

本地工作流包同时封装原签名、派生字符项目、配方版本和来源关系，包含文件hash/许可、大小预算、防重复导入、旧版本和部分损坏恢复。统一作品索引先做本地方案，再验证云同步/批量交付成本；云端权限/额度必须后台原子判断，已有输出免费。

## 自动化交付物

每次研究最少保留来源URL/作者/时间/许可、候选问题、代码绑定、可操作入口、原始失败、修复、桌面和移动证据、实际成本、晋升判断和提交回执。当前核心、生产UI与彩烟合同为可重复脚本，完整执行命令与边界在验证README。工具选择随具体目标，不以榜单排名决定技术方向。
