- edge.json / chrome.json：开发12组合、完整/局部Worker及项目RGBA，实际私人人像2K页面、输出hash和响应观测。
- production-edge.json / production-chrome.json：本地生产UI、下载快照及重开；Chrome额外三档真实高清区域。cases=[]表示本次`--ui-only`没有运行开发模块工程组合，不是零项UI测试。
- legacy-regression-edge.json：14个冻结原浓度/墨色/渲染合同及真实页面恢复。
- input-diagnosis.json：用户768×1024原图及6144×8192偏淡PNG的采样统计，没有图像或用户文件路径。
- colour-diagnosis.json：同尺寸2K、相同15,996枚Placement的3×纯签名 / 75%融合平均亮度。
- styleboard.json：同素材6幅实际引擎样例的设置、输出尺寸、backend及source hash；不是六个正式商业预设。

私人照片、签名PNG、项目文件、SVG和拼版仅在ignored test-results，不提交。工程组合使用合成颜色与字体辅助模板。这里的通过不替代Safari、真实手机、8K低内存、实物印刷或大学生购买验证。
